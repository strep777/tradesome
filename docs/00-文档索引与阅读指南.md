## 2. 三条推荐阅读路径

### 路径 A：我是使用者，只想跑起来

`README.md` → `docs/10-部署运维与用户手册.md` → 安装 akshare（可选）并在「数据中心 → 同步真实行情」取数，或导入 CSV → 首次启动会弹「3 分钟引导」，也可以随时点页面右上角「本页怎么用」。

### 路径 B：我要改策略 / 加功能

`doc/量化交易知识总结.md`（第 4、5、6 章）→ `docs/02-系统架构设计.md` → `docs/15-策略工坊设计.md`、`docs/16-新手引导与自由组合策略设计.md`、`docs/17-真实行情接入设计.md`（先用向导建策略）→ 需要写代码时再读 `docs/05-策略开发规范.md` 与 `tradesome/strategy/base.py`。

### 路径 C：我要验收 / 做代码审查

`docs/01-产品需求规格说明.md`（验收标准）→ `docs/09-测试计划.md` → 运行 `python -m unittest discover -s tests -t . -v`（期望 350 个用例全绿）→ 对照 `docs/13-交付验收报告.md` 的十分钟验收步骤与 `docs/12` 的完成定义逐项打勾。

## 4. 文档维护约定

1. **代码改了，契约文档必须同步**：`docs/03`/`docs/04` 中出现的签名若与代码不一致，视为缺陷；
2. 新增模块必须在 `docs/02` 的目录树和 `docs/04` 的契约表中登记；
3. 重大技术选型变更必须新增 ADR（追加，不修改历史 ADR 的结论）；
4. 文档中的数字（阈值、默认参数）必须与 `core/config.py` 的默认值一致；
5. 所有文档使用 UTF-8 编码、中文标点，代码块标注语言。
