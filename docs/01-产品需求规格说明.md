# TradeSome 产品需求规格说明（PRD）

| 项目 | 内容 |
|---|---|
| 产品名 | TradeSome（本地桌面量化交易工作站） |
| 版本 | 1.0 |
| 日期 | 2026-11-08 |
| 形态 | Windows 本地桌面应用（Python 3.9 + Tkinter，单机、离线可用） |
| 定位 | 面向个人投资者的**学习—研究—回测—模拟实盘**一体化工具，默认不接真实资金 |

---

## 1. 背景与问题

个人做量化有三道坎：

1. **知识碎片化**：策略、回测、风控、成本各讲各的，拼不成系统；
2. **工具门槛高**：专业框架（vnpy/qlib）概念多、依赖重、装不上；脚本式回测又容易犯未来函数、忽略成本；
3. **不敢实盘**：没有安全的模拟环境，回测结果不可信，一上实盘就亏。

TradeSome 的答案是：**一套零依赖、开箱即用、把"知识—策略—回测—风控—模拟盘"串成闭环的桌面软件**，让新手在 5 分钟内跑出第一份可信的回测报告，并在模拟盘中理解真实交易的摩擦。

## 2. 目标与非目标

### 2.1 目标（Goals）

- G1：新手无需安装任何第三方包，双击即可运行；
- G2：内置 6 个**可读、可改、可参数化**的经典策略，覆盖趋势、均值回归、网格、动量轮动、情绪增强；
- G3：回测引擎严格事件驱动，内置 T+1、涨跌停、手数、佣金/印花税/过户费/滑点模型；
- G4：回测、模拟盘共用同一套策略与撮合代码，避免"回测一套、实盘另一套"；
- G5：六道交易前风控闸门 + 一键熔断，所有拦截可审计；
- G6：全中文、简洁优雅、对新手友好的界面，任何危险操作都有确认与解释；
- G7：模块高内聚低耦合，替换数据源/券商/策略/UI 页面不影响其他模块。

### 2.2 非目标（Non-Goals）

- ❌ 不接入真实券商、不下真实订单（本版本仅 Paper Broker；接口预留）；
- ❌ 不做高频/ tick 级撮合（最小粒度 1 分钟，默认日线）；
- ❌ 不做多用户/云端部署/移动端；
- ❌ 不提供投资建议，不承诺任何收益；
- ❌ 不内置付费数据源（提供 CSV 导入与合成数据；AkShare 等适配器留作扩展）。

### 2.3 反目标（Anti-Goals，做到即失败）

- 回测中任何形式的未来数据泄漏；
- 密钥、API Key 以明文落盘；
- 删除数据、重置账户等操作无二次确认；
- UI 主线程被回测/网络阻塞导致"假死"；
- 一个模块的修改导致无关模块测试失败。

## 3. 用户画像与核心场景

| 画像 | 特征 | 核心诉求 |
|---|---|---|
| 小陈（新手） | 会一点 Python，没做过交易 | 看懂什么是回测/回撤，跑通第一个策略 |
| 老李（有经验散户） | 手工交易 5 年，想验证想法 | 快速改参数、看成本影响、模拟盘验证 |
| 阿May（开发者） | 想二次开发 | 清晰的模块边界、可替换的数据源/券商适配器 |

**核心场景（User Story）**

- US-1：小陈打开软件 → 首页引导 → 在数据中心"同步真实行情" → 选择"双均线趋势" → 点击"开始回测" → 看到净值曲线、最大回撤、交易明细，并读到"这意味着什么"的解释。
- US-2：老李在策略实验室把 fast=5 改成 10，保存为新策略，跑两次回测对比成本与夏普。
- US-3：老李启动模拟盘，用 10 万虚拟资金跑 20 个交易日，观察滑点、成交率与风控拦截记录。
- US-4：阿May 新增一个 CSV 数据源适配器，只实现 `MarketDataProvider` 两个方法，其余代码零改动。

## 4. 功能需求

> 编号规则：`F-xx`。每条含**描述**与**验收标准（AC）**。AC 必须可被 `tests/` 中的用例或人工验收清单验证。

### F-01 行情数据管理

**描述**：支持三种数据来源——① 内置合成数据（离线演示）；② 用户 CSV 导入；③ 已落库数据读取。统一存入 SQLite，支持覆盖率查询与删除。

**AC**
1. 首次启动且数据库为空时，首页与数据中心引导"同步真实行情"或导入 CSV；不自动生成任何行情；
2. CSV 导入支持 UTF-8/UTF-8-BOM/GBK 编码，表头支持中英文（日期/开盘/收盘/最高/最低/成交量/成交额 或 date/open/close/high/low/volume/amount）；
3. 导入前做 8 项质量校验，错误行被拒绝并给出**行号 + 原因**，合法行照常入库；
4. 重复导入同一份数据不产生重复记录（主键幂等）；
5. 数据管理页能按标的查看起止日期、bar 数、缺口数、质量问题数。

### F-02 行情图表

**描述**：K 线图 + 叠加指标 + 成交量，支持日线/周线切换与十字光标读数。

**AC**
1. 图表用 Canvas 自绘，窗口缩放时自动重绘且不变形；
2. 红涨绿跌（A 股习惯），MA5/MA20/BOLL 可开关；
3. 十字光标显示该 bar 的日期、OHLC、涨跌幅、成交量；
4. 数据不足 60 根时给出"数据不足"空状态而不是空白图。

### F-03 内置策略库

**描述**：6 个内置策略，均可参数化、可查看原理说明与风险提示。

| key | 名称 | 类型 | 核心参数 |
|---|---|---|---|
| `ma_cross` | 双均线趋势 | 趋势跟踪 | fast, slow, atr_stop, trend_filter |
| `boll_reversion` | 布林带均值回归 | 均值回归 | period, k, stop_loss, exit_at_mid |
| `rsi_reversal` | RSI 超卖反转 | 均值回归 | period, oversold, overbought, stop_loss |
| `grid` | 网格交易 | 网格 | grid_pct, levels, qty_pct, max_position |
| `momentum_rotation` | 动量轮动 | 多标的轮动 | lookback, top_k, rebalance_days, universe |
| `sentiment_boost` | 情绪增强多因子 | 因子/情绪 | lookback, top_k, sentiment_weight, min_score |

**AC**
1. 每个策略有中文名称、一句话简介、详细原理、适用/失效场景、风险等级；
2. 参数以 `ParamSpec` 声明（类型/范围/默认值/说明），UI 自动生成表单并做范围校验；
3. 策略代码 < 200 行，含中文注释，可作为用户自定义策略的模板；
4. 策略只依赖 `Strategy` / `Context` 接口，不 import UI、数据库、网络。

### F-04 策略实验室

**描述**：查看/编辑策略源码，另存为用户策略，安全校验后加载。

**AC**
1. 参数修改即时生效并可"恢复默认"；
2. 源码编辑器支持行号、等宽字体、Ctrl+S 保存；
3. 保存前做 AST 安全检查，命中 `subprocess`/`socket`/`os.system`/`eval`/`exec`/`__import__` 等危险调用时**拒绝保存**并指出行号；
4. 用户策略存入 `var/strategies/<name>.py`，重启后仍可见，可删除（二次确认）；
5. 策略加载失败不影响软件启动，错误在 UI 中以可读中文展示。

### F-05 回测

**描述**：事件驱动回测，支持单标的与多标的组合，输出完整绩效报告。

**AC**
1. 回测参数：起止日期、初始资金、标的（可多选）、周期、手续费率、最低佣金、印花税、过户费、滑点；
2. 严格时序：bar 收盘计算信号 → 订单进入下一 bar 撮合；T+1 可卖数量生效；涨跌停不可成交；成交量占比上限默认 5%；
3. 输出指标 ≥ 15 项：累计收益、年化收益、年化波动、夏普、索提诺、最大回撤、回撤持续、卡玛、胜率、盈亏比、盈利因子、交易次数、换手率、总费用、费用占毛利比；
4. 图表：净值曲线（含基准）、回撤曲线、月度收益热力图；
5. 交易明细表可排序、可导出 CSV；报告可导出 HTML（离线可看）；
6. 回测在后台线程执行，UI 不阻塞，有进度与"取消"按钮；
7. 结果持久化，重启后可在历史记录中重新打开。

### F-06 模拟实盘

**描述**：用历史 bar 按真实时钟回放或加速回放，驱动策略产生订单，Paper Broker 撮合，形成完整实盘闭环。

**AC**
1. 可配置初始资金、回放速度（1x/10x/60x/立即）、标的与策略；
2. 启动后持仓、订单、成交、权益实时刷新（≥1 次/秒）；
3. 订单支持市价/限价；被风控拒绝时在订单列表显示原因；
4. 停止后会话与成交落库，重启可查看历史会话；
5. 崩溃恢复：重启后能读取上次会话的持仓与现金快照（只读展示，可"继续"或"新建"）；
6. 提供"一键熔断"：立即停止策略、撤销全部挂单、禁止新开仓。

### F-07 风控

**描述**：交易前逐单校验 + 账户级监控，规则可配置。

**AC**
1. 六条规则：单笔风险、单标的上限、总仓位上限、当日亏损熔断、回撤熔断、下单频率限制；另含价格带校验与交易时段校验；
2. 每条规则可独立启停、设置阈值，修改后立即生效并写审计；
3. 拦截记录包含：时间、规则、订单摘要、当前值、阈值、处置建议；
4. 熔断状态在顶栏常驻显示，红色高亮；
5. 风控面板展示当前敞口、集中度、当日盈亏、距熔断阈值百分比。

### F-08 组合与账户

**描述**：统一的账户会计，回测与模拟盘共用。

**AC**
1. 现金、冻结资金、持仓市值、总权益、已实现/未实现盈亏、当日盈亏、回撤实时一致；
2. 支持 T+1 可用数量：当日买入次日才可卖；
3. 成交后按加权平均成本更新持仓，卖出计算已实现盈亏（含费用）；
4. 权益快照按 bar 记录，供曲线与指标计算。

### F-09 数据中心

**描述**：数据库概览、导入导出、示例数据生成、清理。

**AC**
1. 展示库文件大小、标的数、bar 总数、时间跨度、最后更新时间；
2. 支持导出某标的全部 bar 为 CSV；
3. 删除标的需输入标的代码确认，并写审计；
4. 提供"清空数据"（确认后清空行情/回测/会话，保留策略与配置，写审计）。

### F-10 设置

**描述**：外观、交易默认值、安全、关于。

**AC**
1. 主题（深色/浅色）切换即时生效并持久化；
2. 字号缩放 90%–130%；
3. 默认手续费/滑点/初始资金可改；
4. API Key 等敏感信息存入 DPAPI 加密保险箱，界面只显示掩码（`sk-****abcd`），支持写入/删除/测试存在性；
5. "重置全部数据"需输入 `RESET` 确认，并自动备份数据库。

### F-11 新手引导与帮助

**描述**：首次启动向导 + 全局帮助。

**AC**
1. 首次启动弹出 4 步向导（认识界面 → 准备数据 → 跑第一个回测 → 看懂结果），可跳过，可再次打开；
2. 关键指标旁有 ⓘ 图标，悬停显示"是什么/怎么读/多少算好"；
3. 空状态页面提供下一步按钮，而不是空白；
4. 帮助中心内置术语表、常见问题、快捷键、风险声明。

### F-12 报告与审计

**描述**：导出与追溯。

**AC**
1. 回测报告可导出 HTML（内联样式、含图表数据表）与 CSV（交易明细）；
2. 审计日志记录：策略加载、参数修改、回测执行、订单提交/拒绝/成交、风控变更、数据删除、密钥写入；
3. 审计日志可按时间/类型筛选，只读，不可从 UI 删除。

### F-13 实盘交易（第二版新增，A 股）

**描述**：在模拟盘之外提供独立的实盘页，通过网关连接模拟柜台或迅投 QMT，真实可下单。

**AC**
1. 默认关闭：设置中 `live.enabled` 默认 `False`，关闭时实盘页只显示「去设置」；
2. 每次启动重新解锁：勾选风险提示并输入「实盘交易」后才允许连接与下单；
3. 柜台可选「模拟柜台」与「迅投 QMT」；QMT 由本机客户端认证，本软件只保存 miniQMT 目录与资金账号；
4. 只发限价单；市价单需显式开启并自动转保护价；每笔下单二次确认；
5. 单笔金额、每日委托笔数、8 条风控规则与熔断全部先于网关执行；
6. 账户、持仓、委托、成交由柜台回报同步；断线时在场单标「待确认」，重连后对账，不猜测成交；
7. 「紧急停止」先撤单再断开；关闭软件前若有实盘会话，先撤单再退出；
8. 连接、下单、撤单、拒单、解锁、紧急停止、对账差异全部写审计与 `live_events`；
9. 自动交易默认关闭，开启后只在交易日设定时间（默认 14:55）跑一次，且仍需已解锁与连接。

### F-14 策略工坊（第三版新增）

**描述**：用户不创建、不编辑任何文件，在「策略库 → 新建策略」里选模板、调参数、加风控叠加层，保存后即可用于回测、模拟盘和实盘。

**AC**
1. 新建策略只通过向导完成，界面不再要求填写文件名/目录，也不暴露代码编辑器；
2. 模板来自内置策略，参数表单由 `ParamSpec` 自动生成，非法值给出中文提示；
3. 支持三个可选风控叠加层：止损、止盈、趋势过滤，填 0 即关闭；
4. 保存后策略立即出现在策略库、回测、模拟盘、实盘的策略下拉框中，无需重启；
5. 支持编辑与删除；重启软件后自定义策略仍存在（存 SQLite，不落 `.py`）；
6. 策略档案只存 JSON，不执行用户代码；回测/实盘仍走统一的风控、费用与审计链路。

### F-15 自由组合策略与新手引导（第四版新增）

**描述**：除了「模板 + 参数」，用户还能从零组合入场与退出条件建立全新策略；同时软件必须主动教用户怎么用，而不是让人猜。

**验收标准**：

- [ ] 策略库「新建策略」提供「从模板开始 / 自由组合」两种方式；自由组合可选 1–4 个入场条件（均线金叉、突破、RSI 低位、布林下轨、动量、放量）与至少一条退出规则（止损、止盈、跌破均线、最长持有），不需要写代码或文件。
- [ ] 保存后立即出现在策略库，并可在回测、模拟盘、实盘下拉框中直接选择；重启后仍在。
- [ ] 条件校验给出中文提示（例如「至少设置一条退出规则」「「突破周期」需在 5–250 之间」）。
- [ ] 首次启动弹出欢迎框（只弹一次，可跳过）；「开始 3 分钟引导」跨 7 个页面高亮目标控件，可上一步/跳过/Esc 退出，完成后记住。
- [ ] 每个页面右上角有「本页怎么用」，打开当前页的 3 条操作步骤。
- [ ] 帮助页有「新手引导与教程中心」，可重看引导；设置页也可重新观看。

### F-16 真实行情与清空测试数据（第五版新增）

用户默认只能用真实行情；软件不再自动生成演示数据。

| 编号 | 验收标准 |
|---|---|
| AC-16.1 | 正常启动不生成任何行情；空库时概览与数据中心明确引导「同步真实行情」或导入 CSV |
| AC-16.2 | `pip install akshare` 后，数据中心可按标的与区间抓取真实日线，失败标的不影响成功标的 |
| AC-16.3 | 抓取结果写成标准 CSV 并入库，回测/模拟盘/实盘读取同一份数据 |
| AC-16.4 | 未安装 akshare 时给出中文安装命令；`python -m tradesome sync-data --check` 可诊断 |
| AC-16.5 | `python -m tradesome clear-data --yes` 清空行情/回测/会话记录，保留策略与配置并写审计 |
| AC-16.6 | `--demo` 仍可用于开发自检，但正常运行路径不会调用它 |

## 5. 非功能需求

| 编号 | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| N-01 | 安全 | 敏感信息加密存储；路径穿越防护；输入白名单校验；默认无网络请求（实盘只连本机已登录的 miniQMT） | 单测 + 代码审查 |
| N-02 | 性能 | 1 万根 bar 单标的回测 ≤ 2s；页面切换 ≤ 100ms；启动 ≤ 3s；常驻内存 ≤ 300MB | 基准脚本 |
| N-03 | 易用性 | 新手 5 分钟内完成首次回测；所有破坏性操作二次确认；错误提示含"下一步怎么做" | 人工验收 |
| N-04 | 可维护性 | 单文件 ≤ 600 行；函数 ≤ 60 行；模块间无循环依赖；公开 API 有类型标注 | 静态检查脚本 |
| N-05 | 可移植性 | Windows 10/11 + Python 3.9+；零第三方依赖；路径不写死盘符 | 干净环境启动 |
| N-06 | 可靠性 | SQLite WAL + 原子写；异常不崩溃主循环；后台任务可取消 | 故障注入测试 |
| N-07 | 可观测性 | 结构化日志（文件+控制台）；UI 事件流；审计表 | 人工 + 单测 |
| N-08 | 合规 | 首启风险声明；实盘默认关闭、需显式解锁与二次确认；不构成投资建议 | 人工验收 |

## 6. 约束

- **运行环境**：Windows 10/11，Python 3.9（`C:\Python39`），Tk 8.6；
- **离线约束**：目标机器无外网，因此**禁止引入任何需要 pip 安装的依赖**；仅使用标准库 + 已预装的 numpy/pandas（可选，核心逻辑不依赖 pandas）；
- **数据约束**：不内置真实行情（版权与体积），演示用确定性合成数据；
- **合规约束**：实盘默认关闭；真实下单只通过本机已登录的 miniQMT，软件自身不保存券商密码。
