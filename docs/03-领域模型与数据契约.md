# TradeSome 领域模型与数据契约

> 本文件是**唯一事实来源（SSOT）**：字段名、类型、单位、默认值在这里定义，代码与数据库必须与之一致。
> 修改本文件 = 修改契约，必须同步更新 `tradesome/core/types.py`、`persistence/migrations.py` 与相关测试。

---

## 1. 建模原则

1. **值对象不可变**：`Bar`、`Fill`、`Order`（对外快照）、`Signal`、`Position` 均为 `@dataclass(frozen=True)`，跨线程安全；
2. **金额一律 `float`，统一在边界舍入**：内部保留原始精度，展示与落库时按 `money.py` 规则（2 位小数，四舍五入 `ROUND_HALF_UP`）；
3. **数量一律 `int`（股）**，不使用"手"作为内部单位，展示时换算；
4. **时间一律 `datetime`（naive，本地交易所时间）**，序列化用 ISO8601 `YYYY-MM-DDTHH:MM:SS`；
5. **不写 `None` 哨兵**：缺省用空集合/0/显式 `Optional` 并在 `__post_init__` 校验；
6. **Python 3.9 兼容**：不使用 `slots=True`、`match`、`X | Y` 运行时注解（文件首行可 `from __future__ import annotations`）。

## 2. 核心类型（`tradesome/core/types.py`）

### 2.1 行情

```python
@dataclass(frozen=True)
class Bar:
    symbol: str
    dt: datetime
    open: float
    high: float
    low: float
    close: float
    volume: float = 0.0      # 股
    amount: float = 0.0      # 元，可缺省为 0
    timeframe: str = "1d"    # "1d" | "1w" | "1m" | "5m" | "15m" | "30m" | "60m"
```
**校验**：`high >= max(open, close, low)`、`low <= min(open, close)`、价格 > 0、`volume >= 0`；`timeframe` 必须在白名单内。


### 2.2 标的与交易规则

```python
@dataclass(frozen=True)
class FeeProfile:
    commission_rate: float = 0.00025   # 双向佣金率
    min_commission: float = 5.0        # 单笔最低佣金（元）
    stamp_tax_rate: float = 0.0005     # 印花税，仅卖出
    transfer_fee_rate: float = 0.00001 # 过户费，双向
    slippage_bps: float = 2.0          # 滑点，基点（1bp=0.01%）

@dataclass(frozen=True)
class Instrument:
    symbol: str            # "600519.SH" / "000001.SZ" / "510300.SH"
    name: str              # "贵州茅台"
    kind: str              # "STOCK" | "ETF" | "INDEX"
    lot_size: int = 100
    price_limit_pct: float = 0.10   # 0.10 / 0.20 / 0.30 / 0.05
    t_plus: int = 1                 # 1 = T+1；0 = T+0（ETF 部分可 T+0）
    tick_size: float = 0.01
    fee: FeeProfile = FeeProfile()
    board: str = "MAIN"             # MAIN/GEM/STAR/BSE/ST
```

```python
    start: date
    end: date

    strategy_key: str = ""

    fee: FeeProfile = FeeProfile()

```

```python
@dataclass
class BacktestResult:
    run_id: str
    config: BacktestConfig
    metrics: dict            # 见 docs/03 §6 指标字典
    equity_curve: list[tuple[datetime, float]]
    drawdown_curve: list[tuple[datetime, float]]
    monthly_returns: dict     # {"2025-01": 0.023, ...}
    trades: list[TradeRecord]
    orders: list[Order]
    logs: list[str]
    started_at / finished_at: datetime
    duration_sec: float
```

`TradeRecord`：一笔**完整往返**交易（开仓→平仓聚合），字段：`symbol, open_dt, close_dt, qty, entry_price, exit_price, pnl, pnl_pct, fees, holding_days, exit_reason`。

## 3. 指标字典（`backtest/metrics.py` 输出键名）

| key | 中文 | 公式/口径 |
|---|---|---|
| `total_return` | 累计收益 | `equity_end/initial - 1` |
| `annual_return` | 年化收益 | `(1+total_return)^(252/n_days)-1` |
| `annual_volatility` | 年化波动 | `std(daily_ret)*sqrt(252)` |
| `sharpe` | 夏普 | `(annual_return - rf)/annual_volatility`，`rf=0.02` |
| `sortino` | 索提诺 | 分母用下行波动 |
| `max_drawdown` | 最大回撤 | `max(1 - equity/peak)` |
| `max_dd_duration` | 回撤持续 | 最长未创新高交易日数 |
| `calmar` | 卡玛 | `annual_return / |max_drawdown|` |
| `win_rate` | 胜率 | 盈利笔数/总笔数 |
| `profit_factor` | 盈利因子 | 总盈利/总亏损 |
| `payoff_ratio` | 盈亏比 | 平均盈利/平均亏损 |
| `trade_count` | 交易笔数 | 平仓笔数 |
| `turnover` | 换手率 | 成交额/平均权益 |
| `total_fees` | 总费用 | 佣金+印花税+过户费+滑点成本 |
| `fee_ratio` | 费用占毛利比 | `total_fees / gross_profit` |
| `exposure` | 仓位暴露 | 持仓市值均值/权益 |
| `benchmark_return` | 基准收益 | 有基准时 |
| `alpha` / `beta` | 阿尔法/贝塔 | 对基准日收益回归 |

**约束**：`annual_volatility < 1e-9` 时 `sharpe=None`，UI 显示"—"而不是除零。

## 4. 数据库模式（SQLite，`persistence/migrations.py`）

```sql
CREATE TABLE IF NOT EXISTS schema_version (version INTEGER NOT NULL);

CREATE TABLE IF NOT EXISTS instruments (
  symbol TEXT PRIMARY KEY, name TEXT NOT NULL, kind TEXT NOT NULL,
  lot_size INTEGER NOT NULL DEFAULT 100, price_limit_pct REAL NOT NULL DEFAULT 0.10,
  t_plus INTEGER NOT NULL DEFAULT 1, tick_size REAL NOT NULL DEFAULT 0.01,
  board TEXT NOT NULL DEFAULT 'MAIN', fee_json TEXT NOT NULL DEFAULT '{}',
  source TEXT NOT NULL DEFAULT 'builtin', updated_at TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS bars (
  symbol TEXT NOT NULL, dt TEXT NOT NULL, timeframe TEXT NOT NULL DEFAULT '1d',
  open REAL NOT NULL, high REAL NOT NULL, low REAL NOT NULL, close REAL NOT NULL,
  volume REAL NOT NULL DEFAULT 0, amount REAL NOT NULL DEFAULT 0,
  PRIMARY KEY (symbol, dt, timeframe)
);
CREATE INDEX IF NOT EXISTS idx_bars_symbol_dt ON bars(symbol, dt);

CREATE TABLE IF NOT EXISTS backtest_runs (
  run_id TEXT PRIMARY KEY, created_at TEXT NOT NULL, strategy_key TEXT NOT NULL,
  params_json TEXT NOT NULL, config_json TEXT NOT NULL, metrics_json TEXT NOT NULL,
  equity_json TEXT NOT NULL, monthly_json TEXT NOT NULL, status TEXT NOT NULL,
  duration_sec REAL NOT NULL DEFAULT 0
);

CREATE TABLE IF NOT EXISTS backtest_trades (
  run_id TEXT NOT NULL, seq INTEGER NOT NULL, symbol TEXT NOT NULL,
  open_dt TEXT, close_dt TEXT, qty INTEGER, entry_price REAL, exit_price REAL,
  pnl REAL, pnl_pct REAL, fees REAL, holding_days INTEGER, exit_reason TEXT,
  PRIMARY KEY (run_id, seq)
);

CREATE TABLE IF NOT EXISTS sessions (
  session_id TEXT PRIMARY KEY, strategy_key TEXT NOT NULL, params_json TEXT NOT NULL,
  started_at TEXT NOT NULL, stopped_at TEXT, initial_cash REAL, status TEXT NOT NULL,
  state_json TEXT,
  mode TEXT NOT NULL DEFAULT 'paper',   -- paper / live（v2）
  gateway TEXT NOT NULL DEFAULT ''      -- sim / qmt（v2）
);

CREATE TABLE IF NOT EXISTS orders (
  order_id TEXT PRIMARY KEY, client_id TEXT NOT NULL, session_id TEXT, run_id TEXT,
  symbol TEXT NOT NULL, side TEXT NOT NULL, qty INTEGER NOT NULL, order_type TEXT NOT NULL,
  limit_price REAL DEFAULT 0, status TEXT NOT NULL, filled_qty INTEGER DEFAULT 0,
  avg_price REAL DEFAULT 0, created_at TEXT, updated_at TEXT, reason TEXT,
  strategy_id TEXT,
  gateway TEXT NOT NULL DEFAULT '',        -- v2
  broker_order_id TEXT NOT NULL DEFAULT '' -- v2
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_orders_client ON orders(client_id);

CREATE TABLE IF NOT EXISTS fills (
  fill_id TEXT PRIMARY KEY, order_id TEXT NOT NULL, symbol TEXT NOT NULL, side TEXT NOT NULL,
  qty INTEGER NOT NULL, price REAL NOT NULL, dt TEXT NOT NULL,
  commission REAL DEFAULT 0, stamp_tax REAL DEFAULT 0, transfer_fee REAL DEFAULT 0,
  slippage_cost REAL DEFAULT 0,
  trade_id TEXT NOT NULL DEFAULT ''        -- v2，柜台成交去重键
);

CREATE TABLE IF NOT EXISTS live_events (   -- v2
  id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL,
  session_id TEXT NOT NULL, kind TEXT NOT NULL, detail TEXT
);
CREATE INDEX IF NOT EXISTS idx_live_events_session ON live_events(session_id, ts);

CREATE TABLE IF NOT EXISTS equity_snapshots (
  session_id TEXT NOT NULL, dt TEXT NOT NULL, equity REAL NOT NULL, cash REAL NOT NULL,
  market_value REAL NOT NULL, day_pnl REAL NOT NULL, drawdown REAL NOT NULL,
  PRIMARY KEY (session_id, dt)
);

CREATE TABLE IF NOT EXISTS strategy_profiles (   -- v3，策略工坊
  profile_id TEXT PRIMARY KEY, name TEXT NOT NULL, template TEXT NOT NULL,
  spec_json TEXT NOT NULL, created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_strategy_profiles_updated ON strategy_profiles(updated_at);

CREATE TABLE IF NOT EXISTS audit_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL, category TEXT NOT NULL,
  action TEXT NOT NULL, actor TEXT NOT NULL DEFAULT 'user', detail TEXT,
  severity TEXT NOT NULL DEFAULT 'INFO'
);
CREATE INDEX IF NOT EXISTS idx_audit_ts ON audit_log(ts);
```

**规则**：只增不删列；版本号单调递增；迁移函数必须幂等（`IF NOT EXISTS` + 版本判断）。
当前 `SCHEMA_VERSION = 3`：v1 建基础表，v2 增加实盘字段与 `live_events`，v3 增加 `strategy_profiles`（工坊档案，JSON 快照）。旧库启动时自动迁移，不丢数据。

## 5. CSV 契约

**表头**（大小写不敏感，允许中文）：

| 标准列 | 中文别名 | 必填 | 说明 |
|---|---|---|---|
| date | 日期/时间 | ✅ | `YYYY-MM-DD` 或 `YYYY/MM/DD` 或 `YYYYMMDD` |
| open | 开盘/开盘价 | ✅ | |
| high | 最高/最高价 | ✅ | |
| low | 最低/最低价 | ✅ | |
| close | 收盘/收盘价 | ✅ | |
| volume | 成交量/量 | ❌ | 缺省 0 |
| amount | 成交额/额 | ❌ | 缺省 0 |

**编码探测顺序**：`utf-8-sig` → `utf-8` → `gbk` → 失败则报"无法识别编码，请另存为 UTF-8"。
**分隔符**：自动探测 `,` / `\t` / `;`。
**文件名约定**：`<symbol>.csv`（如 `600519.SH.csv`）；也接受目录内单文件并在导入时让用户指定代码。

## 9. 金额与费用计算（`backtest/costs.py` 与 `portfolio/account.py` 共用）

```
买入：commission = max(amount * commission_rate, min_commission)
      transfer  = amount * transfer_fee_rate
      现金减少  = amount + commission + transfer
卖出：commission = max(amount * commission_rate, min_commission)
      stamp     = amount * stamp_tax_rate
      transfer  = amount * transfer_fee_rate
      现金增加  = amount - commission - stamp - transfer
滑点：市价买入成交价 = bar.close * (1 + slippage_bps/10000)
      市价卖出成交价 = bar.close * (1 - slippage_bps/10000)
      再按 tick_size 向上/向下取整到最小价位
```

**一致性要求**：回测、模拟盘、报告三处的费用必须调用同一函数，禁止各写一份。
