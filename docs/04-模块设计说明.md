# TradeSome 模块设计说明

> 每个包：**职责 / 公开 API / 不变量 / 失败模式 / 对应测试**。
> 所有 API 以本文件签名为准；实现时如要偏离，先改本文件。

---

## 0. 通用约定

- 每个模块顶部有 `"""模块一句话职责。"""` 与设计说明；
- 公开 API 用 `__all__` 显式导出；
- 依赖通过构造函数传入，模块内**不创建**全局对象；
- 所有可能失败的公开方法：要么抛 `TradeSomeError` 子类，要么返回明确的 `Result`，禁止返回 `None` 表示失败；
- 类型注解齐全；Python 3.9 兼容。

### 3.1 `strategy/base.py`

```python
@dataclass(frozen=True)
class ParamSpec:
    name: str; label: str; type: str            # int/float/bool/choice/str
    default: Any; help: str = ""
    min: float | None = None; max: float | None = None
    step: float | None = None; choices: tuple[str, ...] = ()
    unit: str = ""
    def coerce(self, value) -> Any              # 转换 + 范围校验，失败抛 ValidationError
    def validate(self, value) -> list[str]

@dataclass(frozen=True)
class StrategyMeta:
    key: str; name: str; category: str; risk_level: str   # 低/中/高
    description: str; principle: str; works_when: str; fails_when: str
    tags: tuple[str, ...] = (); version: str = "1.0"

class Strategy:
    meta: StrategyMeta
```

### 3.8 `strategy/rules.py` — 自由组合（条件 DSL）

**职责**：把用户在向导里选的条件翻译成可运行策略，不执行任何用户代码。

- `RULE_TYPES: Dict[str, RuleType]`：`ma_cross` / `breakout` / `rsi_low` / `boll_low` / `momentum` / `volume_surge`，每个 `RuleType` 声明字段范围与中文短语。
- `EXIT_SPECS: Dict[str, ParamSpec]`：`stop_pct` / `take_pct` / `ma_period` / `max_hold_days`，0 表示关闭。
- `default_rules()` / `validate_rules(payload)` / `summarize_rules(rules)` / `describe_partial(...)`：校验返回归一化 dict；摘要生成「当…且…时买入；止损 5%；…」；编辑期用 `describe_partial` 容错预览。
- `RuleStrategy(Strategy)`：`param_specs()` 仅 `weight`；`on_bar` 空仓求值入场、持仓检查退出（止损→止盈→跌破均线→最长持有），`ctx.buy_filter` 不参与（条件 DSL 自带过滤）。
- `make_rule_class(spec)`：动态类名 `Rule_<profile_id>`，meta 标记 `category="自定义"`、描述为条件摘要。

**不变量**：入场条件 1–4 条；至少一条退出规则大于 0；`ma_cross` 快线 < 慢线；参数越界抛 `ValidationError`，不静默夹紧。

## 4. `backtest` — 回测

### 4.1 `backtest/costs.py`
`buy_cost(amount, fee) -> CostBreakdown`、`sell_cost(...)`、`apply_slippage(price, side, fee, tick)`。**唯一费用实现**。

### 4.2 `backtest/matching.py`

```python
class MatchingEngine:
    def __init__(self, instruments, costs, max_volume_ratio=0.05)
    def match(self, order, bar, available_cash, available_qty) -> Fill | None
```
规则（按顺序）：
1. 停牌（volume==0）→ 不成交；
2. 涨跌停（bar.close 达上限且买 / 达下限且卖）→ 不成交（保守假设）；
3. 限价单：买价 < bar.low 或卖价 > bar.high → 不成交；否则以更优价（`min(limit, open)` / `max(limit, open)`）成交；
4. 市价单：以 `bar.open` 成交（**下一根 bar 开盘**，杜绝未来函数）；
5. 数量受 `max_volume_ratio * bar.volume` 与资金/持仓约束；
6. 不足 1 手 → 不成交。

### 4.3 `backtest/engine.py`

```python
class BacktestEngine:
    def __init__(self, config: BacktestConfig, bars_by_symbol: dict[str, list[Bar]],
                 strategy: Strategy, registry: InstrumentRegistry | None = None)
    def run(self, progress: Callable[[int,int],None] | None = None,
            cancel: threading.Event | None = None) -> BacktestResult
```
主循环：
```
for i, dt in enumerate(timeline):          # timeline = 所有标的日子并集，升序
    bars_today = {sym: bar for sym, bar in ...}
    matching.match_pending(...)            # 先撮合上一 bar 产生的订单
    account.mark_to_market(bars_today)
    strategy.on_bars(ctx, bars_today)      # 策略基于当日收盘产生订单（下一 bar 成交）
    account.record_equity(dt)
```
- 订单在 `T` 日收盘产生，`T+1` 开盘撮合 → **无未来函数**；
- 风控在引擎内以 `RiskManager` 实例执行（与实盘同一套）；
- 进度回调每 `progress_every` 根一次；`cancel.is_set()` 时提前返回并标记 `cancelled`；
- 异常：单策略异常 → 记录并继续；连续 10 次 → 中止。

```python
    # 交易
    def apply_fill(self, fill: Fill, inst: Instrument) -> None
    def freeze(self, amount: float) / unfreeze(amount)
    # 估值
    def mark_to_market(self, bars: dict[str, Bar], dt: datetime) -> AccountSnapshot
    def snapshot(self) -> AccountSnapshot
    def settle_day(self, dt: datetime) -> None        # T+1 解冻
    # 查询
    @property cash / equity / positions / realized_pnl
    def position(self, symbol) -> Position | None
    def available_qty(self, symbol) -> int
```
**不变量**：
- `cash >= -1e-6`（不允许透支；不足则拒单）；
- `available_qty <= qty`；卖出后 `available_qty` 减少；
- 权益 = 现金 + 冻结 + Σ(持仓 × 最新价)；
- 已实现盈亏按**加权平均成本**计算并扣除费用；
- 所有公开方法加 `threading.RLock`。

### 6.1 `risk/rules.py`


8 条规则：
| rule_id | 名称 | 逻辑 |
|---|---|---|
| `single_trade` | 单笔风险 | `qty*price / equity <= single_trade_pct` |
| `single_symbol` | 单标的上限 | 成交后该标的市值/权益 ≤ 25% |
| `gross_exposure` | 总仓位上限 | 成交后总市值/权益 ≤ 80% |
| `daily_loss` | 当日亏损 | 当日亏损 ≥ 3% → 禁止开仓；≥5% → 强制平仓信号 |
| `drawdown` | 回撤熔断 | 回撤 ≥15% → 仅允许减仓；≥20% → 全部禁止 |
| `order_rate` | 下单频率 | 每分钟订单数 ≤ 20 |
| `price_band` | 价格带 | 限价偏离现价 > 10% 拒绝（防胖手指） |
| `session` | 交易时段 | 非连续竞价时段拒绝市价单 |


## 12. `gateway` / `trading` — 实盘扩展

### 12.1 `gateway/protocol.py`

行协议 v1：一条消息一行 UTF-8 JSON。

| 形状 | 字段 |
|---|---|
| 请求 | `{v, id, cmd, params}` |
| 响应 | `{v, id, ok, data}` 或 `{v, id, ok:false, error:{code,message}}` |
| 事件 | `{v, event, data}` |

- 命令：`hello / ping / connect / disconnect / subscribe / order / cancel / cancel_all / account / positions / orders / trades`；
- 事件：`status / account / position / order / trade / tick / log / heartbeat`；
- 回报数据类：`AccountUpdate`、`PositionUpdate`、`OrderUpdate`、`TradeUpdate`、`TickUpdate`；
- 错误码：`E_AUTH / E_PROTOCOL / E_TIMEOUT / E_DISCONNECTED / E_GATEWAY / E_REJECTED`；
- 解析函数对字段名做容错（`balance/volume/traded/order_id` 等），未知字段忽略。

不变量：同一连接内 `id` 唯一；响应必须回显请求 `id`；服务端事件不带 `id`。

### 12.2 `gateway/base.py`、`sim.py`、`qmt.py`

```python

    name: str
    def set_listener(self, listener: Listener) -> None
    def start(self) -> None
    def stop(self) -> None
    def place_order(self, order: dict) -> str          # 返回柜台委托号
    def cancel(self, broker_order_id: str, symbol: str = "") -> bool
```

- `QmtGateway`：进程内调用迅投 `xtquant`（随 miniQMT 安装，不需要 vnpy）。连接流程

### 12.3 `trading/oms.py`、`live_broker.py`、`live_market.py`

```python
class OrderManager:
    def register(self, order: Order) -> Order
    def get(self, key: str) -> Optional[Order]         # 先 order_id 再 client_id
    def apply_update(self, update: OrderUpdate) -> Optional[Order]
    def apply_trade(self, update: TradeUpdate) -> Optional[Fill]   # trade_id 去重
    def mark_unknown(self, reason: str) -> int
    def reconcile(self, remote: List[OrderUpdate]) -> List[str]
```

- 状态机只允许前进：`UNKNOWN < PENDING < SUBMITTED < PARTIAL < {FILLED, CANCELLED, REJECTED}`；终态不再变化；
- 柜台先报成交、后返回下单结果时，`register` 保留更高级状态，不把已成交单改回"已报"；
- 找不到本地单但柜台回报 `qty>0` 时，登记为 `EXT-<broker_id>` 只读单，防止漏记；
- `LiveBroker` 实现 `execution.ports.Broker`：限价单原样下发，市价单转为保护价限价（默认 ±1%，不超过涨跌停）；
- `LiveMarket` 实现策略侧只读行情：本地日线 + 当日合成 bar；没有行情时明确报错，不用旧价硬撮合。

### 12.4 `LiveTradeService` 不变量

1. 必须 `arm()` 且配置 `live.enabled=True` 才能开会话；启动软件后默认锁定；
2. 只发限价单；市价单需显式打开 `live.allow_market_orders`，且服务层仍转保护价；
3. 单笔金额、每日委托笔数、风控八条规则、熔断全部先于网关执行；
4. `client_id` 幂等；重复提交返回同一订单；
5. 断线时在场单标 `UNKNOWN`，不推断成交；重连后对账；
6. `stop_session`/`emergency_stop` 先 `cancel_all` 再断开；
7. 所有真实委托、撤单、连接、解锁、紧急停止都写审计与 `live_events`。
