# TradeSome 策略开发规范

> 目标：让一个懂 Python 基本语法的人，**30 分钟内**写出一个能回测、能上模拟盘与实盘的策略；同时保证策略不会破坏软件。

---

## 0. 首选方式：策略工坊（不写文件）

如果你只是想改均线周期、加一个止损，不需要看后面的代码规范：

1. 打开「策略库」→ 右上角「新建策略」；
2. 选一个模板，填参数；
3. 按需设置「风控止损 / 风控止盈 / 风控趋势均线」，填 0 关闭；
4. 保存。策略立刻可用于回测、模拟盘和实盘，重启后仍在。

档案存在 SQLite 的 `strategy_profiles` 表，是 JSON，不是 `.py` 文件。详见 [策略工坊设计](15-策略工坊设计.md)。

下面 §§1–11 是给需要写自定义指标、复杂退出逻辑的开发者看的**可选**路径。

### 0.1 自由组合（从零搭一条全新的策略）

如果你不想选模板，可以在「策略库 → 新建策略 → 自由组合」里直接搭：

1. 选 1–4 个入场条件（全部满足 / 任一满足）：均线金叉、突破前高、RSI 低位、布林下轨、动量、放量；
2. 至少开一条退出：止损、止盈、跌破均线、最长持有；
3. 设单标的仓位，右侧会实时生成一句中文摘要；保存即可回测/模拟/实盘。

条件由 `strategy/rules.py` 解释，**不是**用户代码，也不生成 `.py` 文件。要写自定义指标或复杂逻辑时，才看下面的手写策略章节。

## 1. 策略是什么

一个策略 = **一个类** + **一组参数** + **几个回调**。

```
行情 bar 到达 ──► on_start()（一次）
              ──► on_bars()/on_bar()（每根 bar）
                      │
                      ├─ ctx.history()  读历史
                      ├─ ctx.indicator() 算指标
                      └─ ctx.buy()/sell() 下单 ──► 风控 ──► 撮合 ──► on_order()
              ──► on_stop()（一次）
```

**回测、模拟盘与实盘跑的是同一份策略代码**，区别只在 `ctx` 背后的网关：回测用历史 bar 撮合，模拟盘用回放 bar 撮合，实盘把委托交给 `LiveBroker` 并由柜台回报驱动。策略里不要写「如果实盘」的分支——仓位、风控与费用都交给下面几层。

## 2. 最小可运行策略

```python
# var/strategies/my_first.py
from tradesome.strategy.base import ParamSpec, Strategy, StrategyMeta
from tradesome.core.types import Bar


class MyFirst(Strategy):
    meta = StrategyMeta(
        key="my_first",
        name="我的第一个策略",
        category="趋势",
        risk_level="中",
        description="价格上穿 20 日均线买入，下穿卖出。",
        principle="均线代表一段时间的平均成本，上穿说明买方力量占优。",
        works_when="单边趋势行情",
        fails_when="横盘震荡（反复被打脸）",
        tags=("均线", "入门"),
    )
    params = (
        ParamSpec("period", "均线周期", "int", 20, min=5, max=120, help="越大越慢"),
        ParamSpec("weight", "单次仓位", "float", 0.3, min=0.05, max=0.9, unit="比例"),
    )

    def on_bar(self, ctx, bar: Bar):
        closes = ctx.history(bar.symbol, self.p.period + 1, "close")
        if len(closes) < self.p.period + 1:
            return
        ma_now = sum(closes[-self.p.period:]) / self.p.period
        ma_prev = sum(closes[-self.p.period - 1:-1]) / self.p.period

        if closes[-2] <= ma_prev and closes[-1] > ma_now and ctx.position_of(bar.symbol) == 0:
            ctx.buy(bar.symbol, weight=self.p.weight, reason="上穿均线")
        elif closes[-2] >= ma_prev and closes[-1] < ma_now and ctx.position_of(bar.symbol) > 0:
            ctx.close(bar.symbol, reason="下穿均线")
```

保存后刷新策略列表即可回测。**没有 import 任何外部库，没有网络、文件、子进程。** 注意：从第三版起，界面默认不提供「策略代码」入口；手写文件属于进阶用法，仍会被注册表加载并经过 AST 沙箱校验。

## 3. 接口契约

### 3.1 `StrategyMeta`（必填）

| 字段 | 类型 | 要求 |
|---|---|---|
| `key` | str | 全局唯一，小写字母/下划线，`^[a-z][a-z0-9_]{2,31}$` |
| `name` | str | 中文显示名，≤ 12 字 |
| `category` | str | 趋势/均值回归/网格/动量/因子/其他 |
| `risk_level` | str | 低/中/高（用于 UI 标签与默认仓位建议） |
| `description` | str | 一句话，≤ 40 字 |
| `principle` | str | 原理，2–5 句 |
| `works_when` / `fails_when` | str | 适用/失效场景（新手最需要） |
| `tags` | tuple | 可选 |

### 3.2 `ParamSpec`（参数声明）

```python
ParamSpec(name, label, type, default, *, min=None, max=None, step=None,
          choices=(), help="", unit="")
```
- `type ∈ {"int","float","bool","choice","str"}`；
- `int/float` 必给 `min/max`（防御性，UI 与加载时都会校验）；
- 参数名必须是合法标识符，且不与基类属性冲突；
- **新增参数必须有默认值**，保证老配置仍能加载。

### 3.3 生命周期回调

| 回调 | 调用时机 | 允许做的事 |
|---|---|---|
| `on_start(ctx)` | 回测/会话开始，bar 循环前 | 初始化指标缓存、读参数、`ctx.log` |
| `on_bars(ctx, bars: dict[str, Bar])` | 每根时间步（多标的） | 下单、查询；**默认实现**遍历调用 `on_bar` |
| `on_bar(ctx, bar)` | 单标的简写 | 同上 |
| `on_order(ctx, order)` | 订单状态变化（成交/拒绝） | 记录、调整状态；**不要**在这里下新单 |
| `on_stop(ctx)` | 结束/停止 | 清理、打印统计 |

**禁止**：在 `on_start` 里下单（此时无行情）；在 `on_order` 里递归下单（可能死循环）。

### 3.4 上下文 API（`StrategyContext`）

| 方法 | 说明 | 返回 |
|---|---|---|
| `ctx.buy(symbol, qty=None, weight=None, limit_price=None, reason="")` | 买入；`qty` 与 `weight` 二选一 | `order_id` / `None` |
| `ctx.sell(...)` | 卖出（可卖数量受 T+1 限制） | 同上 |
| `ctx.close(symbol, reason="")` | 清仓该标的 | 同上 |
| `ctx.close_all(reason="")` | 清仓全部 | — |
| `ctx.position(symbol)` | 持仓对象或 `None` | `Position` |
| `ctx.position_of(symbol)` | 持仓股数 | int |
| `ctx.available(symbol)` | 可卖股数（T+1） | int |
| `ctx.cash` / `ctx.equity` | 现金/总权益 | float |
| `ctx.positions` | 全部持仓 | tuple |
| `ctx.history(symbol, n=60, field="close")` | 截至当前 bar 的历史序列 | list[float] |
| `ctx.bar(symbol)` | 当前 bar | `Bar` / None |
| `ctx.price(symbol)` | 最新价 | float |
| `ctx.indicator(name, symbol, **kw)` | 内置指标（见 §4） | list[float] |
| `ctx.log(msg, level="info")` | 写策略日志（进入回测日志/事件流） | — |
| `ctx.now()` | 当前模拟时间 | datetime |

**关键语义**
- **所有数据截至当前 bar（含），绝无未来数据**；
- `weight=0.3` 表示"用当前权益的 30% 买入"，内部按手数向下取整，不足 1 手返回 `None`；
- 同一根 bar 内相同方向的重复下单会被幂等键去重；
- 下单只是"提交意图"，实际成交在**下一根 bar**（回测）或下一 tick（模拟盘）；
- 被风控拒绝不抛异常，返回 `None`，原因见 `on_order` 的 `order.reason`。

## 4. 指标库（`ctx.indicator` / `tradesome.strategy.indicators`）

| name | 参数 | 输出 | 说明 |
|---|---|---|---|
| `sma` | `n` | 均线 | 简单移动平均 |
| `ema` | `n` | 均线 | 指数移动平均 |
| `rsi` | `n=14` | 0–100 | 相对强弱 |
| `macd` | `fast=12, slow=26, signal=9` | `(dif, dea, hist)` | 需用 `ctx.indicator("macd", ...)` 返回三元组 |
| `boll` | `n=20, k=2` | `(mid, upper, lower)` | 布林带 |
| `atr` | `n=14` | 波动 | 真实波幅 |
| `kdj` | `n=9, k=3, d=3` | `(k, d, j)` | 随机指标 |
| `roc` | `n=20` | 涨跌幅 | 动量 |
| `donchian` | `n=20` | `(upper, lower)` | 唐奇安通道 |
| `std` | `n=20` | 标准差 | |
| `obv` | — | 能量潮 | |

**多返回值指标**返回 `tuple[list[float], ...]`；单值返回 `list[float]`。所有列表与输入等长，前 `n-1` 位为 `nan`。

## 5. 六个内置策略（可直接抄改）

| key | 名称 | 入场 | 出场 | 风控 |
|---|---|---|---|---|
| `ma_cross` | 双均线趋势 | 快线上穿慢线 + 收盘价 > MA120（可选） | 快线下穿慢线 / ATR 追踪止损 | ATR×2 止损，单笔 20% |
| `boll_reversion` | 布林带均值回归 | 收盘跌破下轨 | 回到中轨 / 止损 -6% | 单标的 25% |
| `rsi_reversal` | RSI 超卖反转 | RSI < 30 且价格止跌（收盘 > 前收） | RSI > 65 / 止损 -5% | 分批建仓 |
| `grid` | 网格 | 价格每跌 `grid_pct` 买入一份 | 每涨 `grid_pct` 卖出一份 | 最大仓位上限 |
| `momentum_rotation` | 动量轮动 | 每 `rebalance_days` 取 `roc(lookback)` 前 `top_k` | 排名跌出前 K 换出 | 等权，最多 K 只 |
| `sentiment_boost` | 情绪增强多因子 | `0.7*动量分 + 0.3*情绪分` 前 `top_k` | 分数跌出前 K | 情绪缺失按 0 处理 |

每个内置策略都提供：完整中文注释、`works_when/fails_when`、参数说明、默认值经过示例数据验证（能产生交易）。

## 6. 安全沙箱规则（用户策略）

保存/加载用户策略时执行 AST 扫描，命中即拒绝：

**禁止 import**：`os`、`sys`、`subprocess`、`socket`、`shutil`、`ctypes`、`importlib`、`pickle`、`marshal`、`builtins`、`http`、`urllib`、`requests`、`multiprocessing`、`threading`。
**禁止调用**：`eval`、`exec`、`compile`、`__import__`、`open`、`input`、`globals`、`locals`、`getattr`、`setattr`、`delattr`、`breakpoint`、`exit`、`quit`、`os.system`、`os.popen`。
**禁止属性**：`__globals__`、`__subclasses__`、`__builtins__`、`__code__`、`__class__`（用于逃逸的典型路径）。
**允许 import**：`math`、`statistics`、`datetime`、`collections`、`typing`、`dataclasses`、`tradesome.strategy.base`、`tradesome.core.types`。

> 说明：这不是"绝对安全"的沙箱（Python 内无法做到），而是**防止误用与明显恶意**的护栏；软件本身不联网、不接真实资金，风险可控。

## 7. 情绪数据

`strategy/sentiment.py` 定义：

```python
@dataclass(frozen=True)
class SentimentScore: symbol: str; date: date; score: float   # -1 极度悲观 .. +1 极度乐观
class SentimentProvider(Protocol):
    def get(self, symbol: str, d: date) -> float
```

- 默认 `OfflineNeutralProvider`（恒 0，保证离线可用）；
- 用户可放 `var/sentiment/<symbol>.csv`（列：`date,score`）→ `CsvSentimentProvider` 自动生效；
- 在线大模型（如 DeepSeek）适配器作为**扩展点**：实现 `get()`，在设置页填入 Key（存加密保险箱），默认关闭。文档给出 20 行示例，不内置网络调用。

**使用纪律**：情绪分只能作为**加权因子**，不能单独作为买卖依据；缺失按 0；必须防止用未来新闻（数据日期 ≤ 当前 bar 日期）。

## 8. 常见错误清单（Review Checklist）

| 错误 | 症状 | 正确做法 |
|---|---|---|
| 未来函数 | 回测收益异常高（年化 > 100%） | 只用 `ctx.history` 到当前 bar；不要 `shift(-1)` |
| 用收盘价成交 | 回测虚高 | 下单后由引擎在下一 bar 开盘撮合 |
| 忽略费用 | 高频策略"看起来赚钱" | 引擎默认计费，不要自己加 |
| 满仓单票 | 一次黑天鹅归零 | `weight <= 0.3`，留现金 |
| 不设止损 | 回撤 50%+ | ATR 或固定百分比止损 |
| 参数过拟合 | 样本内完美、样本外崩溃 | 用 `walkforward` 检验；参数不选"最优点"而选"平台区" |
| 在 `on_order` 下单 | 递归/重复下单 | 只在 `on_bar(s)` 决策 |
| 依赖外部状态 | 回测与实盘结果不一致 | 所有状态放实例属性，`on_start` 重置 |

## 10. 测试与验收

策略作者应至少验证：

1. 示例数据上能跑通，产生 ≥ 1 笔交易；
2. 交易明细无"同日买卖同一标的"（T+1 生效）；
3. 最大回撤、费用占比在合理范围（费用占比 > 50% 说明换手过高）；
4. 参数在边界值（min/max）不崩溃；
5. `python -m tradesome --cli backtest --strategy <key> --symbols 510300.SH` 可复现结果。

内置策略由 `tests/unit/test_builtin_strategies.py` 统一验证上述 5 条。
