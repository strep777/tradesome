# TradeSome UI/UX 设计规范

> 目标：**第一次打开就知道该点什么；每个数字都能读懂；每个危险操作都拦一下。**
> 视觉关键词：macOS 风格、留白、层次、数字优先、浅色为默认。
>
> 2026-11 起默认外观为 **macOS 风格（浅色）**，仍保留深色/浅色两套色板；
> 三套主题共用同一组令牌，页面代码不感知主题差异。

---

## 1. 设计原则

1. **一个页面一个主任务**：回测页只做回测，不塞设置。
2. **渐进披露**：高级参数默认折叠；新手只看得到 5 个必填项。
3. **数字优先**：KPI 用大号等宽数字，单位与正负号清晰（`+12.34%`、`-¥1,234.56`）。
4. **状态可见**：任何耗时 > 300ms 的操作必须有进度或骨架；任何失败必须有原因与下一步。
5. **危险操作可逆**：删除/重置/清空 → 二次确认 + 输入确认词 + 自动备份。
6. **不用颜色做唯一信息载体**：涨跌同时用符号（▲▼）与文字。
7. **中文优先**：术语首次出现给中文解释，英文缩写放括号里。

### 2.3 间距与圆角

- 间距刻度：`4 / 8 / 12 / 16 / 24 / 32`；
- 卡片内边距 16，卡片间距 12；macOS 风格下内容区左右留白 24；
- 圆角：卡片 12（Canvas 绘制，四角真正圆角），按钮 8（胶囊按钮 height/2），输入框 8，标签 999；
- 阴影：Tk 不支持柔和投影，用 1px `border` + `surface_alt` 模拟层次；不使用粗描边。

### 2.5 macOS 风格要点（v1.4 起）

TradeSome 的视觉语言对齐 macOS Sonoma 的原生应用，而不是"给网页套一层深色皮"：

1. **分组背景 + 白色卡片**：窗口 `#F2F2F7`，卡片纯白、12px 圆角、1px `#D8D8DE` 边框，没有厚重阴影。
2. **侧栏是半透明感的分组列表**：`surface_alt` 底、无边框；选中项是蓝色圆角胶囊（`accent` 填充 + 白字），不是左侧色条。
3. **控件是圆角胶囊**：主按钮/次按钮都是 8px 圆角，高度 30；开关是 44×24 的滑动开关，不是勾选框。
4. **工具栏极简**：左侧应用名与页面名，右侧只有时钟、主题、帮助；不使用大色块。
5. **数字用等宽字体**，标题用系统中文字体，字号阶梯 20/13/10/9，字重只用 Bold/Normal。
6. **颜色语义沿用 A 股**：涨红跌绿；系统蓝只用于交互，不用于涨跌。
7. **动效克制**：只有 hover 亮度变化与 1px 按压位移，不做弹跳/缩放。

> 实现约束：Tk 没有原生圆角与阴影，圆角由 `Canvas` 画（`widgets/card.py`、`button.py`），
> 开关由 `Canvas` 画（`widgets/form.py`）；因此**页面代码仍然只调用 `Card / Button / Toggle` 的公开方法**，
> 换主题或换控件实现不影响 11 个页面。

## 3. 组件规范

### 3.1 按钮

| 类型 | 样式 | 使用场景 |
|---|---|---|
| Primary | accent 填充、白字、8px 圆角 | 每屏最多 1 个（开始回测/启动模拟盘） |
| Secondary | `surface_alt` 填充、text 字、无边框 | 次操作（导出、重置） |
| Ghost | 透明、hover 变 `accent_soft`、accent 字 | 工具栏、卡片内 |
| Danger | danger 填充、白字 | 删除、熔断、重置 |
| Success / Warning | success/warning 填充 | 极少使用（解锁、提示） |
| Icon | 24×24，无边框 | 关闭、刷新、信息 |

- 高度：30（md）/ 26（sm），宽度由文字测量得出，左右内边距 14；
- 禁用态：`surface_alt` 底 + `faint` 字，无 hover、无手型；
- 点击反馈：按下亮度变化，松开触发回调；按下后移出按钮取消触发；
- 键盘：Tab 聚焦，Enter/Space 触发；
- 实现：`tk.Canvas` 画圆角矩形 + 居中文本（`widgets/button.py`），页面只依赖 `set_enabled/set_text`。

### 3.2 卡片 Card

```
┌──────────────────────────────────────────┐
│ 标题 (H2)                    [操作按钮]  │
│ 副标题/说明 (muted, 可选)                 │
│ ──────────────────────────────────────── │
│ 内容                                     │
└──────────────────────────────────────────┘
```

- 白色 `surface` 底、12px 圆角、1px `border`，无外阴影；
- 内边距 16（紧凑 12/14）；卡片间距 12；
- 圆角由 `Card` 内部的 `Canvas` 绘制，`Card.body` 仍是普通 Frame，页面把内容 pack 进 `body` 即可；
- 卡片内不嵌套卡片；需要分组时用 `Divider` 分隔。

### 3.3 KPI 卡片

```
┌────────────────────┐
│ 总收益       ⓘ     │
│ +12.34%            │  ← 22pt Consolas，up 色
│ ▲ ¥12,345.67       │  ← 9pt muted
│ ~~~~~~~~~~~~~      │  ← Sparkline 32px
└────────────────────┘
```
网格：一行 4 个（宽度 < 1200 时 2 个）。ⓘ 悬停显示"是什么/怎么读/多少算好"。

### 3.4 表格

- 表头 `surface_alt`、10pt muted、无竖线；
- 行高 30；斑马纹用 `surface` / `surface_alt` 的极浅差异；
- 选中行 `accent_soft`，文字不变色；
- 数字右对齐、文本左对齐、日期居中；
- 涨跌列带颜色 + 符号；
- 空状态：居中图标 + 一句说明 + 一个行动按钮；
- 超过 200 行分页（每页 100/200/500 可选）；
- 右键菜单：复制、导出选中。

### 3.5 表单

- 标签在左（宽 120），控件在右；说明文字在控件下方 9pt muted；
- 输入框：`surface_alt` 底、8px 圆角、1px `border`，聚焦时边框变 `accent`；
- 开关：44×24 胶囊 + 16px 圆形滑块，开启为 `accent`，关闭为 `border`；点击整条或按 Space 切换；
- 必填项标签后加红色 `*`；
- 校验失败：控件边框 danger + 下方红字原因，**不弹窗**；
- 数值输入支持上下键步进、滚轮（聚焦时）、千分位显示（失焦格式化）；
- 参数表单由 `ParamSpec` 自动生成：int/float → Entry，bool → Toggle，choice → Combobox，str → Entry。

### 3.6 Toast / Modal / 空状态

- **Toast**：右上角，宽 320，3s 自动消失，最多堆叠 3 条；类型 info/success/warning/error；error 停留 6s；
- **Modal**：遮罩 60% 黑，居中卡片 480 宽，Esc 关闭，焦点陷阱；
- **确认框**：危险操作需输入确认词（如标的代码 / `RESET`）；
- **空状态**：图标（Canvas 绘制）+ 标题 + 一句解释 + 主按钮。

### 3.7 加载与进度

- < 300ms：无提示；
- 300ms–2s：按钮内 spinner + 禁用；
- > 2s：进度条 + 百分比 + "取消"；
- 骨架屏用于表格/图表首次加载。

## 4. 页面设计

### 4.1 概览 Dashboard

```
[首次使用引导条：3 步完成设置 →]（可关闭，settings.first_run=false 后不再出现）
[KPI ×4：总权益 | 今日盈亏 | 持仓数 | 风控状态]
[左 2/3：权益曲线（近 90 天）] [右 1/3：快捷操作 + 最近回测列表]
[底部：数据概览（标的数/bar 数/最后更新）+ 风险提示]
```
空状态：无数据时 KPI 显示 `—`，引导条强调"同步真实行情或导入 CSV"。

### 4.2 行情 Market

- 顶部：搜索框 + 周期切换（日/周/月）+ 显示区间（默认全部历史；近 3 年/近 1 年）+ 刷新；
- 左侧列表：全市场代码/名称/最新价/涨跌幅/成交量/数据状态；
- 历史不足 1000 根的标的被选中时，自动在后台补齐该股全部历史日线（状态行显示进度，失败可点「补齐历史」重试）；
- 主图上方：`YYYY-MM-DD` 输入框 + [定位]（跳到最近交易日并居中显示 120 根）、[重置]、[补齐历史]；
- 主图：K 线 + 均线/BOLL 开关 + 成交量副图；**滚轮缩放、左键拖动平移、双击重置**，
  窗口右上还有 [＋][－][重置]；
- 缩放时 X 轴取当前可见日期、Y 轴按可见最高最低自适应，成交量按可见区间重新归一；
- 图表左上角显示「滚轮缩放 · 拖动平移 · 双击重置（N 根）」。
- 右侧信息条：最新价、涨跌幅、最高/最低、成交量、数据区间（随缩放/定位显示当前可见首末日期）；
- 十字光标跟随，顶部显示 OHLC。

### 4.3 策略库 Strategies

- 左侧列表：策略名、类别、风险、来源（内置/自定义）、参数数；自定义排在最前；
- 右侧详情：名称、类别 · 风险 · 版本、key、描述、原理、适用行情、失效场景、标签、参数表；
- 底部动作：[用此策略回测] [在实验室调参]；自定义策略额外有 [编辑] [删除]；
- 右上角 [新建策略] 打开「策略工坊」向导，不跳转到实验室，也不要求写文件。

**策略工坊向导（模态卡片，760×640）**

```
策略名称 [__________________]   模板 [双均线趋势 · 趋势 v]
模板说明（一句话 + 三个可选叠加层说明）
──────────────────────────────────────────────
模板参数（两列，ParamSpec 自动生成）
风控止损 (%)   风控止盈 (%)
风控趋势均线   单标的仓位 …
──────────────────────────────────────────────
[不需要写代码或文件…]                     [取消] [保存并可用]
```

- 标题栏可拖动；内容区可滚动；底部按钮固定；
- 切换模板重建参数表单，但保留已填的叠加层；
- 校验失败在表单下方显示红字原因，不弹第二个窗口。

### 4.4 策略实验室 Lab

- 单页「参数试跑」：策略 / 标的 / 区间 / 参数表单 / [试运行回测] [恢复默认]；
- 右侧 KPI + 净值图 + 试跑交易表；
- 顶部提示：「要保存成自己的策略，去策略库 → 新建策略，不需要写文件」；
- 原「策略代码」页签已移除，避免把文件概念重新暴露给普通用户。

### 4.5 回测 Backtest

```
[配置卡片（可折叠）]
 标的（多选）| 起止日期 | 初始资金 | 策略 + 参数 | 费用（高级）
 [开始回测] [取消]
[进度条（运行中）]
[结果 Tabs：概览 | 净值与回撤 | 月度收益 | 交易明细 | 日志]
[导出 HTML] [导出 CSV] [保存到历史]
```
概览：8 个指标卡 + 一句"人话解读"（如"最大回撤 18.2%，意味着最差时账户从高点缩水近两成"）。

### 4.6 模拟盘 Live

```
[控制条：策略 | 速度 | 初始资金 | 启动/暂停/停止 | 一键熔断]
[KPI ×4：总权益 | 今日盈亏 | 持仓市值 | 可用现金]
[左：持仓表] [右：订单表（含拒绝原因）]
[底部：事件流（时间 · 类型 · 说明）]
```
"模拟"角标常驻左上；运行中 Header 显示绿点 + 会话 ID。

### 4.7 实盘 Live Trade

```
[状态条：已连接·已解锁 | 会话 ID | 刷新] [未连接]
[解锁卡：未启用 → 去设置；未解锁 → 风险勾选 + 输入「实盘交易」+ 解锁；已解锁 → 本次有效 + 立即上锁]
[连接卡：柜台 sim/qmt | userdata_mini 目录/资金账号/账号类型 | 策略 | 标的 | 模拟资金 | 连接/断开/紧急停止]
[KPI ×4：总资产 | 可用资金 | 持仓市值 | 浮动盈亏]
[左：手动下单（只限价）] [右：持仓表]
[委托表：状态 + 原因 + 撤销选中] [成交表]
[自动交易卡：开关 | 计划时间 | 现在跑一轮]
```

- 未解锁时所有下单入口禁用，并在卡片里告诉用户「下一步做什么」；
- 连接/断开/紧急停止是三种不同语义：断开保留会话与持仓，紧急停止先撤单再断开；
- 真实委托一律二次确认；确认按钮使用 Danger 样式；
- 状态用颜色与文字双编码：已连接绿、未连接灰、错误红、待确认（UNKNOWN）黄；
- 顶部常驻「实盘」标识，避免与模拟盘混淆；关闭窗口前若在运行，先提示并撤单。

### 4.8 风控 Risk

- 顶部状态条：`正常 / 仅减仓 / 已熔断`（颜色区分）+ 当前回撤/当日亏损；
- 规则列表：开关 + 阈值输入 + 说明 + 最近触发时间；
- 敞口图：横向条形（各标的市值占比 + 现金）；
- 拦截记录表：时间、规则、订单、当前值/阈值、建议。

### 4.9 数据中心 Data Center

- 标题行：[同步真实行情]（主按钮，单只多年日线）[同步全部 A 股]（约 1 分钟，全市场当日快照）[导入 CSV] [导出选中] [删除选中]；
- 库概览：标的数、K 线根数、起止日期；[打开数据目录]；
- 覆盖表：标的、名称、周期、根数、起始、结束；
- 数据质量卡：选中即检查，列出错误/提醒明细与 CSV 约定；
- 空状态：一段说明 + [同步真实行情]，并提示可先[同步全部 A 股]；不提供"生成演示数据"（演示数据只用于开发/自测）。

同步弹窗（AkshareSyncModal）：

- 顶部状态：akshare 可用 / 不可用（附完整 `pip install akshare` 命令，未安装时禁用开始）；
- 标的多选列表（带名称，默认 3 个蓝筹）；开始/结束日期（YYYY-MM-DD）；复权方式；
- 进度条；完成后显示成功标的数、K 线数与失败原因前 3 条；
- 运行中禁用关闭，避免用户以为没在跑。

## 7. 可访问性与适配

- 键盘可完成全部核心流程（不使用鼠标也能回测）；
- 不仅靠颜色区分涨跌（▲/▼ + 正负号）；
- 高 DPI：进程启动时声明 Per-Monitor DPI Aware V2（见 7.1），字体用 pt 由 Tk 缩放，
  布局尺寸统一走 `theme.px()`，禁止页面里写死像素；
- 窗口最小 1180×720（按 100% DPI 计，实际随 DPI 因子放大），低于此出现横向滚动（内容区）；
- 主题切换（macOS / 深色 / 浅色）后所有页面立即重绘，不重启。

### 7.1 高 DPI 与清晰度

Windows 在 125%/150% 缩放时，如果进程不声明 DPI 感知，系统会把整个窗口当位图拉伸，
文字和 1px 边框就会发虚。TradeSome 的处理：

1. **创建 Tk 之前**调用 `tradesome.ui.enable_dpi_awareness()`：
   优先 `SetProcessDpiAwarenessContext(-4)`（Per-Monitor V2），回退
   `shcore.SetProcessDpiAwareness(2)`，再回退 `user32.SetProcessDPIAware()`；
   非 Windows 或调用失败时静默跳过（不影响启动）。
2. `Shell` 创建后读取 `winfo_fpixels("1i") / 96` 得到 `dpi_factor`，写入 `theme.set_dpi()`；
   显式设置 `tk scaling = dpi/72`，保证 10pt 字在 125% 下是 16–17 个物理像素。
3. `theme.px(v)` 返回 `v × user_scale × dpi_factor`，所有 padding、列宽、行高、
   图表高度、窗口尺寸都经过它；**字体不要再乘 dpi**，否则会二次放大。
4. `_ChartBase` 的 padding 与画布高度也走 `theme.px()`；线宽保持 1–2 物理像素，
   高 DPI 下反而更锐利。
5. 截图脚本不再乘 1.25 补偿：进程感知后 `winfo_screenwidth()` 与 `ImageGrab` 都是物理像素，
   两者比值为 1.0。
6. 验收：125% 与 150% 下文字边缘锐利、细边框不发灰；100% 下布局与之前一致；
   11 页截图无裁切、无重叠。

> 取舍：感知 DPI 后窗口可用的"逻辑高度"变小，因此页面统一允许纵向滚动；
> 固定高度的卡片（图表、表格）用 `theme.px()` 随 DPI 放大，不靠 Windows 拉伸。
