## 4. 共用夹具（`tests/support.py`）

```python
def make_bars(symbol="600519.SH", days=260, start=date(2022,1,4),
              base=100.0, drift=0.0004, vol=0.018, seed=7) -> list[Bar]
def make_trend_bars(..., step=0.5, volume=1_000_000) -> list[Bar]   # 严格上涨
def bars_until(bars, date) -> list[Bar]
def clone_bars(bars) -> list[Bar]
class TempWorkspace:          # TemporaryDirectory 包装，root 为 Path
def build_memory_container(root=None, with_demo=False) -> Container
```

**确定性**：所有随机数据用固定种子；时间从固定日期起算；测试中不依赖 `datetime.now()` 做断言（模拟盘/UI 只断言"有值"而非具体值）。

**Windows 注意事项**：
- 临时目录必须在 `Database.close()` 之后清理，否则 `PermissionError WinError 32`；
- 内存库 `close()` 后再查询会重连出空库，验证落库的用例改用文件库；
- `sqlite3.connect()` 用 `finally: conn.close()`，上下文管理器不会关闭连接。

**运行方式**：

```bat
python -m unittest discover -s tests -t . -v
```

> pytest 不可用（离线环境无法安装），因此统一用标准库 `unittest`。通过与否以输出中的 `OK` 为准：PowerShell 会把被测代码写到 stderr 的日志行当成错误，导致进程退出码为 1。

## 5. 用例矩阵（关键断言）

### 5.1 内核

| 用例 | 断言 |
|---|---|
| Bar 非法 OHLC | 抛 `ValidationError`，消息含"最高价" |
| `round_money(1.005)` | `1.01`（HALF_UP，非银行家舍入） |
| 总线通配订阅 | 发布 `order.filled` 时 `*` 订阅者收到 |
| 订阅者抛异常 | 不影响其他订阅者，且产生 `app.error` |
| 并发发布 1000 次 | 无异常，`recent()` 长度 ≤ 500 |
| 配置损坏 | 返回默认值 + 备份文件存在 + 警告非空 |
| 配置未知字段 | 忽略且不报错 |
| 节假日 | 2025-10-01 非交易日；2025-10-09 是 |
| 时段 | 09:20 → AUCTION；12:00 → LUNCH；15:01 → CLOSED |
| 代码推断 | `688981.SH` → STAR/0.20；`300750.SZ` → GEM/0.20；`830799.BJ` → BSE/0.30 |
| 涨跌停 | 前收 10.00 → (9.00, 11.00)，按 tick 对齐 |

### 5.2 数据

| 用例 | 断言 |
|---|---|
| upsert 同批两次 | 行数不变（幂等） |
| 区间查询 | 边界含首含尾，升序 |
| 质量：缺口 | 5 个交易日后缺失 → 1 条 `E_GAP` |
| 质量：OHLC 矛盾 | `high < close` → `E_OHLC` |
| 合成数据确定性 | 同 seed 两次 `fetch_bars` 完全相等 |
| 合成数据合法性 | 全部 bar 通过 `check_bars`；涨跌幅 ≤ 板块限制 |
| CSV 中文表头 | 正确解析 |
| CSV GBK | 正确解析 |
| CSV 坏行 | 合法行入库，坏行进入报告，不抛异常 |
| 周线聚合 | 5 根日线 → 1 根周线，OHLC 正确，量求和 |

### 5.3 指标（与手算/已知序列对照）

| 用例 | 断言 |
|---|---|
| SMA([1..5], 3) | `[nan,nan,2,3,4]` |
| EMA 收敛 | 常数序列输出常数 |
| RSI 全涨 | 趋近 100；全跌趋近 0 |
| BOLL 常数序列 | upper==lower==mid |
| ATR 首值 | `nan`；之后非负 |
| MACD 长度 | 与输入等长；hist = dif - dea |
| 空/短输入 | 返回等长 nan，不抛异常 |

### 5.4 回测与撮合

| 用例 | 断言 |
|---|---|
| **无未来函数** | 构造"次日必涨"数据，若策略用次日信息则收益异常；断言 `on_bar` 时 `history` 末值 == 当日收盘 |
| 下一 bar 开盘成交 | 订单在 T 日产生，成交价 == T+1 开盘价（含滑点） |
| T+1 | 当日买入当日卖出 → 卖单被拒/数量为 0 |
| 涨停不成交 | 买入订单在涨停 bar 保持未成交 |
| 成交量约束 | 订单量 > 5% 成交量 → 部分成交或缩量 |
| 手数 | 买入 150 股 → 100 股；科创板 250 → 200 |
| 最低佣金 | 小额成交佣金 == 5.0 |
| 印花税 | 仅卖出收取 |
| 权益守恒 | `equity == cash + frozen + Σ市值`（误差 < 1e-6） |
| 取消 | 置位 cancel 后 ≤ 1 根 bar 内返回，`cancelled=True` |
| 指标 | 单边上涨策略 `total_return > 0`；横盘策略 `trade_count == 0` |
| 空数据 | 抛 `BacktestError`，消息含"没有行情数据" |
| 夏普除零 | 零波动 → `sharpe is None` |

### 5.5 账户

| 用例 | 断言 |
|---|---|
| 加权成本 | 10 元买 100、12 元买 100 → avg_cost 11 |
| 部分卖出 | 成本不变，已实现盈亏 = (卖价-成本)*量-费 |
| T+1 结算 | 次日 `available_qty == qty` |
| 现金不足 | 买入被拒，`cash` 不变 |
| 快照 | 字段齐全，`drawdown ∈ [0,1]` |

### 5.6 风控

| 用例 | 断言 |
|---|---|
| 单笔超限 | `allowed=False, rule_id="single_trade"` |
| 单标的超 25% | 拒绝 |
| 总仓位超 80% | 拒绝 |
| 当日亏 3% | 开仓拒绝、平仓允许 |
| 当日亏 5% | `HALT` |
| 回撤 20% | 全部拒绝，状态 `HALT` |
| 频率 | 第 21 单/分钟拒绝 |
| 价格带 | 偏离 15% 拒绝 |
| 时段 | 午休市价单拒绝 |
| 熔断解除 | `reset_day` 后恢复 OK |
| 审计 | 每次拒绝新增一条 `risk.reject` |

### 5.7 执行

| 用例 | 断言 |
|---|---|
| 幂等 | 同 `client_id` 提交两次 → 只有 1 个订单，返回同一 `order_id` |
| 拒绝原因 | 中文、非空、含具体数值 |
| 部分成交 | `filled_qty < qty`，状态 `PARTIAL` |
| 撤单 | 未成交单可撤；已成交不可撤 |
| 事件 | 提交/成交/拒绝各发一次事件 |

### 5.8 安全

见 `docs/06` §7（6 组用例）。

### 5.9 内置策略

对 6 个策略参数化跑同一套断言：
1. 示例数据 3 年、初始 10 万 → 能跑通且 `trade_count ≥ 1`（`grid`/`rsi` 允许 0，用趋势/震荡数据分别验证）；
2. 无同日买卖同标的；
3. `total_fees < 初始资金 × 10%`；
4. 参数取 min/max 不崩溃；
5. 指标键齐全（≥ 15 项）。

### 5.10 架构约束（`test_architecture.py`，7 个用例）

实现的检查（全部基于 AST，不 import 被测模块）：

- `core/` 只能用第 1 层相对导入（`from .x import y`），不得 `from ..`，也不得 import 其它 `tradesome.*`；
- 只有 `ui/` 可以 import `tkinter`/`ttk`；只有 `cli.py` 与 `__main__.py` 可以 `print`；
- `data/persistence/strategy/portfolio/risk/backtest/execution` 不得 import `tradesome.ui` 或 `tradesome.app`（`cli.py` 是组合根，允许）；
- 禁止 `pandas/numpy/matplotlib/PySide6/PyQt5`；
- 每个包必须有 `__init__.py`；
- 单文件 ≤ 800 行、单函数 ≤ 150 行（比初版的 600/60 放宽，原因是
  `persistence/repositories.py` 把 10 个仓储放在一个文件里便于对照 schema；
  该阈值只用于阻止文件继续膨胀，不追求形式上的短函数）。

> 未实现初版中的"每个包 `__all__` 非空"：`core` 等包用显式导入即可，
> 强制 `__all__` 只会增加维护噪音。

## 7. UI 测试策略

**原则**：不做像素级断言（脆弱），做"可构造 + 可切换 + 关键控件存在 + 无异常"。

实际实现 `tests/ui/test_ui_smoke.py`（4 个用例）：

- 模块导入时探测 Tk：能创建并销毁一个隐藏 root 才启用，否则 `skipUnless`；
- `setUp` 用内存库 + 演示数据构建 `Shell`，把 `show_error` 替换成列表以捕获弹窗；
- 逐页 `navigate`，断言页面对象存在、`_current` 正确、`winfo_ismapped()` 为真、无错误；
- 覆盖主题切换、导航只保留一个页面、侧栏只有当前项高亮；
- 截图不进测试：由 `tools/capture_screenshots.py` 单独执行，避免 CI 依赖桌面分辨率。
