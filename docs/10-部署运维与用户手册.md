# TradeSome 部署、运维与用户手册

> 面向两类人：**只想用的人**（第 1–4 章）与**要维护的人**（第 5–9 章）。

---

## 1. 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809+ / Windows 11（x64） |
| Python | 3.9 及以上（仅用标准库） |
| 内存 | 4GB 起（建议 8GB） |
| 磁盘 | 300MB（含数据与日志） |
| 显示 | 1360×860 起，最小 1180×720 |
| 网络 | **不需要**（首次运行、回测、模拟盘全部离线） |
| 权限 | 普通用户即可，无需管理员 |

> 支持 macOS/Linux 运行核心与 CLI（Tk 需系统自带），但 UI 视觉按 Windows 调校。

## 2. 安装（三种方式）

### 方式 A：解压即用（推荐）

1. 将 `tradesome/` 整个目录（含 `doc/`、`docs/`、`tradesome/` 包）复制到任意位置，例如 `D:\Tools\TradeSome`；
2. 确认已安装 Python 3.9+，命令行执行 `python --version`；
3. 双击 `start_tradesome.cmd`。

`start_tradesome.cmd` 内容：

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
python -m tradesome %*
if errorlevel 1 pause
```

### 方式 B：命令行

```bash
cd D:\Tools\TradeSome
python -m tradesome
```

### 方式 C：开发模式

```bash
python -m tradesome --log-level DEBUG
python -m tradesome --demo        # 仅开发：生成合成行情后启动
```

**应用本体零第三方依赖**：跑软件本身不需要 `pip install`。`akshare` 只在「同步真实行情」时使用，软件**首次启动会在后台自动安装**（需要联网，约 1–3 分钟），不需要手动执行命令。

- 自动安装失败：同步弹窗会给出原因与「重试安装」按钮；
- 离线环境：把 `akshare` 及其依赖的 wheel 放到 `vendor/akshare/`，软件会改用本地包；
- 诊断：`python tools\akshare_sync.py --check`（可选，仅排查用）。

## 3. 首次运行

1. 启动后出现**欢迎框**（560×360）：「第一次用？先花 3 分钟走一遍。」
2. 点「开始 3 分钟引导」会跨 7 个页面高亮下一个该点的控件（概览 → 数据中心 → 策略库 → 回测 → 模拟盘 → 实盘 → 帮助），每步只高亮一个目标；可「上一步」「跳过」，Esc 随时退出。走完或跳过会记在本地，下次不再弹。
3. 不想现在走：点「先自己看看」。之后可以从「帮助 → 新手引导与教程中心 → 重新观看」，或「设置 → 外观 → 重新观看新手引导」再打开。
4. 每个页面右上角都有「本页怎么用」，列出该页的 3 条操作步骤；不确定时先看它。
5. **首次启动是空库**：不会自动生成任何演示行情。去「数据中心 → 同步真实行情」抓取真实日线，或「导入 CSV」。
6. 首次运行会创建：

```
var/
├─ settings.json        # 你的设置
├─ tradesome.db         # 行情、回测、订单、审计
├─ secrets.dat          # 加密后的密钥（若你添加过）
├─ logs/tradesome.log   # 运行日志
├─ strategies/          # 你保存的策略
├─ exports/             # 导出的报告
├─ backups/             # 自动备份
└─ data/akshare/        # 同步下来的真实 CSV（可删，库内有副本）
```

## 4. 使用速查

### 4.1 五分钟跑通第一个回测

1. 数据中心 → 「同步全部 A 股」拿全市场快照（约 1 分钟），再对要回测的标的
   「同步真实行情」抓多年日线（或导入 CSV）；没有数据时回测页会直接提示；
2. 回测 → 标的选 `510300.SH`，策略选「双均线趋势」；
3. 点「开始回测」，等待进度条完成；
4. 看 6 个 KPI、权益/回撤曲线与逐笔交易；
5. 点「导出报告」保存 Markdown / CSV 到 `var/exports/`。

### 4.2 改一个策略参数

策略实验室 → 选策略 → 改「快线周期」→ 点「开始回测」对比 → 满意后「保存为新策略」。

### 4.2.1 看某只股票的全部历史 K 线

1. 行情页 → 搜索代码或名称 → 选中该股；
2. 若只有当日快照，图表会自动在后台补齐 1990 年至今的日线（状态行显示进度，约 1–2 秒）；
3. 用「近 3 年 / 近 1 年 / 近 5 年 / 全部历史」切换显示区间（默认近 3 年），周期可切日/周/月；
4. 补齐失败时点图表右上「补齐历史」重试，或到数据中心「同步真实行情」。

### 4.3 新建自己的策略（不写文件）

1. 策略库 → 右上角「新建策略」；
2. 填名称，选一个模板，调参数；
3. 可选：风控止损（%）、风控止盈（%）、风控趋势均线，填 0 即关闭；
4. 「保存并可用」→ 列表出现「自定义」策略，重启后仍在。

档案存 SQLite 的 `strategy_profiles` 表，可在策略库中编辑或删除。需要自定义指标时才写 `.py`（见 `docs/05` 进阶）。

### 4.3.1 从零组合一条全新策略（不选模板）

1. 策略库 →「新建策略」→ 顶部切到「自由组合」；
2. 组合方式选「全部满足（且）」或「任一满足（或）」；
3. 「+ 添加条件」选 1–4 个入场条件：均线金叉、突破前高、RSI 低位、布林下轨、动量、放量；每个条件只有 1–2 个数字参数；
4. 退出规则至少开一条：止损 %、止盈 %、跌破均线天数、最长持有天数（0 表示关闭）；
5. 设单标的仓位（5%–50%）；右侧摘要会实时变成「当…且…时买入；止损 5%；…」；
6. 「保存并可用」→ 自动出现在回测、模拟盘、实盘的下拉框，重启后仍在。

这是条件 DSL，不执行用户代码，也不生成 `.py` 文件。详见 `docs/16`。

### 4.4 跑模拟盘

模拟盘 → 选策略与速度（10x）→「启动」→ 观察持仓/订单/事件流 →「停止」。
红色「一键熔断」会立即停止策略、撤销挂单、禁止新开仓。

### 4.5 实盘演练（不上真钱）

1. 设置 → 实盘 → 打开「启用实盘」→ 保存；
2. 实盘页 → 勾选「已了解风险」→ 输入「实盘交易」→ 解锁；
3. 柜台选「模拟柜台（本地演练）」→ 选标的（如 `600519.SH`）→ 连接；
4. 手动下单：选方向、数量、价格 →「提交委托」→ 二次确认；
5. 观察委托/成交/持仓与总资产变化；撤单可点「撤销选中」或双击委托；
6. 「紧急停止」会先撤掉所有未成交委托再断开，状态回到「未连接」。

模拟柜台与真实 QMT 走同一套契约、风控、审计与界面，所以演练熟了就只差连接方式。

### 4.6 接真实 A 股（迅投 QMT）

1. 在券商开通 QMT/miniQMT 权限，安装并登录 QMT 客户端（保持运行）；
2. 找到 `userdata_mini` 目录，例如 `D:\QMT\userdata_mini`；
3. 设置 → 实盘：启用实盘，填目录、资金账号、账号类型（普通/信用），保存；
4. 实盘页：勾选风险提示 → 输入「实盘交易」解锁；
5. 柜台选「迅投 QMT」，确认目录/账号 → 连接；
6. 账户/持仓/委托/成交由柜台回报同步；下单仍是限价 + 二次确认。

miniQMT 未启动、目录错误、账号未订阅时，实盘页顶部会显示中文错误；在场委托标「待确认」，
重连后自动对账。此时优先「紧急停止」，再到券商端核对。细节见 `docs/14`。

### 4.7 使用真实行情

**在线同步（akshare）**

1. 直接点「同步真实行情」——首次会自动安装 akshare，无需命令；
2. 数据中心 → 「同步真实行情」→ 勾选标的、选区间与复权方式 → 开始；
3. 完成后表格出现标的与根数；失败项会显示原因，其它标的不受影响。

**导入自己的 CSV**

数据中心 → 「导入 CSV」→ 选择文件（文件名建议 `<代码>.csv`，如 `600519.SH.csv`）→ 查看质量报告 → 完成。
CSV 格式见 `docs/03` §5；最少需要 `date,open,high,low,close` 五列。也支持券商/数据商导出的中文表头。

## 5. 命令行接口（CLI）

```bash
python -m tradesome --help
python -m tradesome --demo                          # 仅开发：生成合成行情后启动 UI
python -m tradesome --safe-mode                     # 不加载用户策略
python -m tradesome --reset-ui                      # 重置界面设置
python -m tradesome --log-level DEBUG
python -m tradesome --version

# 真实行情与清理
python -m tradesome sync-data --symbols 600519.SH,000858.SZ --start 2022-01-01
python -m tradesome clear-data --yes                # 清空行情/回测/会话，保留策略与配置

# 无界面模式
python -m tradesome demo-data --force               # 仅开发/测试
python -m tradesome backtest --strategy ma_cross --symbols 600519.SH \
       --start 2022-01-01 --end 2025-12-31 --cash 100000 --param fast=5 --param slow=20
python -m tradesome selftest                        # 快速自检（DB/策略/回测）
```

**退出码**：0 成功；1 参数错误；2 运行错误；3 数据缺失（例如库内没有行情）。

## 6. 备份、恢复与迁移

### 6.1 备份

```bat
xcopy /E /I /Y var D:\Backup\TradeSome-%DATE%
```
或软件内：设置 → 关于 → 「备份数据库」（写入 `var/backups/`）。

**备份内容**：`tradesome.db`、`settings.json`、`strategies/`、`secrets.dat`（若含密钥，注意保管）。

### 6.2 恢复

1. 关闭软件；
2. 用备份覆盖 `var/` 下同名文件；
3. 重新启动（迁移会自动执行）。

### 6.3 迁移到新机器

复制整个目录 → 安装 Python 3.9 → 双击 `start_tradesome.cmd`。
**注意**：DPAPI 加密的 `secrets.dat` **不能跨 Windows 用户账户解密**，换机器后需重新录入密钥。

## 7. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击无反应 | 未装 Python / 关联错误 | 命令行 `python -m tradesome` 看报错 |
| 提示"找不到 tkinter" | Python 安装未勾选 tcl/tk | 重装 Python，勾选 "tcl/tk and IDLE" |
| 界面模糊 | 高 DPI 未适配 | 右键 `python.exe` → 属性 → 兼容性 → 更改高 DPI 设置 → 应用程序 |
| 启动报"配置损坏" | `settings.json` 非法 | 软件已自动备份并恢复默认；也可删掉该文件 |
| 回测很慢 | 标的多/年限长 | 减少标的到 ≤ 10，年限 ≤ 5 年 |
| 同步提示 akshare 不可用 | 自动安装失败（断网/代理/权限） | 在同步弹窗点「重试安装」；离线时把 wheel 放到 `vendor/akshare/`；仍失败可看 `var/logs/tradesome.log` |
| 同步全部失败 | 网络/代理、接口限流 | 换时段、减少标的、加大 `--sleep`；先跑单标的定位 |
| 某只票没有数据 | 停牌/退市/代码错 | 换标的或扩大区间；也可导入 CSV |
| 图表空白 | 数据不足 | 至少需要 120 根 K 线；换标的或先同步/导入更长区间 |
| 模拟盘无成交 | 风控拦截/涨跌停/停牌 | 看订单表"拒绝原因"与风控页拦截记录 |
| 中文乱码 | 控制台编码 | `chcp 65001`；CSV 用 UTF-8 |
| 数据库被锁 | 同时开了两个实例 | 只保留一个窗口；`var/*.db-wal` 会自动恢复 |
| 杀毒软件报警 | 打包/脚本误报 | 项目无网络、无捆绑；可加白名单 |

**日志位置**：`var/logs/tradesome.log`（最近 3000 行足够定位）。
**获取诊断信息**：设置 → 关于 → 「复制诊断信息」（版本、路径、Python 版本、最近错误）。

## 8. 升级与卸载

### 升级

1. 备份 `var/`；
2. 用新版本目录覆盖程序文件（**保留 `var/`**）；
3. 启动时自动迁移数据库（幂等，失败会回滚并提示）。

### 卸载

删除程序目录即可（绿色软件，不写注册表、不装服务）。
若要彻底清除个人数据，删除 `var/` 目录。

## 9. 日常运维建议

| 周期 | 动作 |
|---|---|
| 每日 | 看一次日志有无 ERROR；模拟盘结束后检查权益快照 |
| 每周 | 备份 `var/`；清理 `var/exports/` 旧报告 |
| 每月 | 检查数据库大小（> 500MB 时归档旧数据）；回顾风控拦截记录 |
| 每季 | 用 walk-forward 复验在用策略；更新节假日表（跨年时） |

## 10. 安全注意事项

1. 不要把 `var/secrets.dat` 发给他人；
2. 不要在网络共享盘运行（SQLite 锁不可靠）；
3. 不要用管理员权限运行（不必要，且增大误操作影响面）；
4. 软件不联网；若你自行改造接入在线数据源，请自行评估风险；
5. 模拟盘 ≠ 实盘：滑点、流动性、情绪均不同，**不要据回测结果直接实盘**。
