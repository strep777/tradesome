# TradeSome 交付验收报告

> 版本 1.1 · 2026-11-08 · 对应 `docs/12` 任务树的 P0–P15（第二版新增实盘接入）。
> 本报告回答三个问题：**交付了什么**、**凭什么说它能用**、**还有什么做不到**。

## 1. 交付概览

| 项目 | 内容 |
|---|---|
| 软件名称 | TradeSome（本地量化交易工作站） |
| 形态 | Windows 桌面端，Tkinter 单窗口，离线运行 |
| 运行环境 | Windows 10/11 + Python 3.9（实测 `C:\Python39\python.exe`），零第三方运行时依赖 |
| 启动方式 | 双击 `start_tradesome.cmd`，或 `python -m tradesome` |
| 数据 | 本地 SQLite（`var/tradesome.db`）+ 内置合成行情 + CSV 导入导出 |
| 交易 | 回测 + 历史回放模拟盘 + **A 股实盘（模拟柜台 / 迅投 QMT 原生直连）**；T+1、涨跌停、手数、费用、滑点、成交量约束、8 条风控规则 |
| 代码规模 | `tradesome/` 约 113 个 Python 文件、约 15,900 行 |
| 测试规模 | `tests/` 21 个测试文件、341 个用例，全部通过 |
| 文档 | `doc/` 领域知识 1 份 + `docs/` 工程文档 16 份（00–15，含本报告） |

### 4.3 手工冒烟路径

1. 双击 `start_tradesome.cmd` → 概览页出现 8 个标的、9,336 根 K 线；
2. 行情页选中「600519.SH 贵州茅台」→ K 线、MA5/MA20、成交量、OHLC 浮层正常；
3. 策略库 →「新建策略」→ 选「双均线趋势」→ 参数 fast=5/slow=20 → 保存 → 列表出现「我的双均线」（来源：自定义）；
   选中它 →「用此策略回测」→ 自动跳到回测页并预选；
4. 回测页「开始回测」→ 6 个 KPI、权益/回撤图、逐笔交易表在 1 秒内出现；「导出报告」生成 md + 2 个 csv；
5. 模拟盘 → 开始 → 权益曲线逐 bar 推进，订单表出现成交；暂停/继续/停止正常；
6. 风控 → 修改单笔仓位为 5% 保存 → 模拟盘下一单被拒并出现在审计；
7. 数据中心 → 导入 `assets/600519.SH.csv` → 60 根、质量报告通过；
8. 帮助 → 文档目录按钮打开 `docs/`；
9. **实盘演练**：设置 → 实盘 → 打开「启用实盘」→ 保存 → 实盘页勾选风险、输入「实盘交易」解锁 →
   柜台选「模拟柜台」→ 连接 → 手动下单 100 股限价 → 二次确认 → 委托表出现成交、持仓与总资产变化；
   点「紧急停止」→ 先撤单再断开，状态回「未连接」；
10. **QMT 自检**（没装 QMT 也能验证）：`python -c "from tradesome.gateway.qmt import QmtGateway; print(QmtGateway.available())"`，
    未安装时打印 `False`；装好并登录 miniQMT、填好目录与资金账号后，实盘页选「迅投 QMT」连接。

## 5. 验收期间发现并修复的缺陷

历次迭代合计 28 个真实缺陷（全部已修，且多数补了回归用例）：

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| 1 | `validate_filename` 允许文件名恰为 `..` | 用户策略可写到上级目录 | 增加 `set(text) <= {"."}` 拦截（`security/validation.py`） |
| 2 | 日志脱敏先匹配键值、后匹配 Bearer，导致 `Authorization: Bearer <token>` 只脱掉 "Bearer" | 令牌明文进日志 | 先 `_BEARER_PATTERN.sub("Bearer ***")` 再跑键值规则（`security/redaction.py`） |
| 3 | `MarketDataRepository._covers/_slice` 直接调 `start.date()` | 服务层传 `date` 时 `AttributeError`，回测/行情查询崩溃 | 新增 `_as_date()` 归一化（`data/repository.py`） |
| 4 | `StrategyRegistry.remove_user` 用 `cls.__module__` 反推文件路径 | 沙箱把模块名固定为 `tradesome_user_strategy`，用户策略删不掉 | 注册时记录 `_user_files[key] = path`（`strategy/registry.py`） |
| 5 | `StrategyRegistry.__init__` 未加载用户目录 | "保存策略后重启消失" | discover 后补 `reload_user()` |
| 6 | `Account.position_list` 是 `@property`，6 处按方法调用 | `LiveService.status()`、回测强平路径 `TypeError` | 去掉 6 处括号（`execution/live_engine.py`、`backtest/engine.py`、`app/services/live_service.py`） |
| 7 | `MarketService.export_csv` 以 `(path, symbol, bars)` 调 `export_bars_csv(bars, path)` | UI「导出 CSV」必崩 | 参数顺序改正（`app/services/market_service.py`） |
| 8 | `Shell.toggle_theme` 用 `theme=` 关键字调 `set_appearance(theme_name=)` | 点「切换主题」崩溃 | 改为 `theme_name=`（`ui/shell.py`） |

## 6. 已知限制（不是缺陷，是设计边界）

1. **真实下单依赖 QMT 客户端**：TradeSome 自带模拟柜台；接真实 A 股需要券商开通 QMT/miniQMT 权限、安装并登录客户端，然后把 `userdata_mini` 目录与资金账号填进设置。本软件不保存券商密码，券商认证由 QMT 客户端完成。
2. **只做 A 股/ETF、限价为主**：市价单需显式开启并会转成保护价限价；不支持期货、期权、港股/美股、做空与融资融券。
3. **行情需同步或导入**：正常启动为空库，不内置真实历史数据；首次同步会自动安装 akshare（需联网，装到软件目录），也可导入 CSV。`--demo` 生成的合成行情只用于开发自检，不应作为研究结论。QMT 网关只做交易、不订阅行情，报价仍来自本地日线或手动刷新。
4. **沙箱是同进程 AST 护栏**：能拦住危险 import、`eval/exec/open`、属性逃逸、相对导入，但 Python 同进程无法做到绝对隔离。定位是"防止从网上复制的策略误伤"，不是"运行不可信代码"。
5. **单账户、单币种**：不支持多账户分仓；自动交易每日只在设定时间跑一次，避免无人值守连续下单。
6. **回测是日线级**：无 tick/分钟级撮合；信号在收盘产生、次日开盘成交，不模拟盘中滑点路径。
7. **无自动更新、无云同步**：数据与配置都在本机 `var/`，备份即复制该目录。

## 7. 十分钟验收步骤

```bat
cd F:\tradesome

REM 1) 静态检查：所有模块可编译
python -m compileall -q tradesome

REM 2) 全量测试（期望最后一行 OK，341 tests）
python -m unittest discover -s tests -t . -v

REM 3) 命令行自检（不打开窗口，验证装配、策略、回测）
python -m tradesome selftest

REM 4) 无数据冷启动（应提示先同步）→ 开发用合成数据 → 跑一次回测
python -m tradesome backtest --strategy ma_cross --symbols 600519.SH --cash 100000
python -m tradesome demo-data --force
python -m tradesome backtest --strategy ma_cross --symbols 600519.SH --cash 100000

REM 4b) 真实行情（已安装 akshare 且能联网时）
python -m tradesome sync-data --symbols 600519.SH --start 2022-01-01

REM 5) 启动图形界面
start_tradesome.cmd

REM 6) QMT 自检（未安装时打印 False，属预期）
python -c "from tradesome.gateway.qmt import QmtGateway; print(QmtGateway.available())"
```

验收判定：第 2 步输出 `OK`；第 3、4 步输出 6 个指标且退出码 0（第 4 步第一次应因空库返回 3）；第 5 步打开概览页，按 §4.3 走一遍主路径与实盘模拟柜台流程无报错。

## 8. 结论

十三项要求均有对应交付物与可复现证据：知识文档、18 份工程文档、桌面软件、6 个内置策略 + 工坊模板策略 + 自由组合策略、341 个通过的测试、11 页界面截图（另附实盘连接、向导、引导、同步与全市场共 22 张）、30 个已修缺陷、真实行情同步（akshare，首次启动自动安装到软件目录），以及一套可真实使用的 A 股实盘通道（模拟柜台 + 迅投 QMT 原生直连）。
软件可以在没有网络、没有第三方包的 Windows 机器上直接运行，用于学习策略、验证想法、练习完整交易流程；接真实资金时，它通过进程内 `xtquant` 连接本机 miniQMT，默认关闭、每次启动重新解锁、下单二次确认，并把所有委托与风控拦截写入审计。

仍做不到的：替你安装券商接口、提供真实历史行情、保证任何策略盈利。这些边界在 README、帮助页与每份文档中都写明了。

后续演进建议：子进程隔离用户策略 → 分钟级数据与撮合 → 多账户/多策略分仓 → 参数寻优与组合回测。
