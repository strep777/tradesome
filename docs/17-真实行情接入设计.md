## 1. 目标与非目标

**目标**

1. 正常启动的软件不再生成、也不再包含任何合成/演示行情；首次打开是空库，界面明确引导去同步真实数据。
2. 用 [akshare](https://akshare.akfamily.xyz/tutorial.html) 抓取 A 股 / ETF / 指数的真实日线，写入本地 SQLite，回测、模拟盘、实盘使用的是同一份数据。
3. 保留 CSV 导入作为离线/自备数据通道；两者写入同一张 `bars` 表。
4. 旧的演示数据、回测记录、模拟盘会话可以一键清空，并留下审计记录。

**非目标**

- 不把 akshare 变成应用本体的硬依赖。akshare 依赖 pandas/requests，版本变化快；TradeSome 仍是 Python 3.9 + 标准库 + Tkinter 的零第三方依赖应用。
- 不做分钟级/tick 历史抓取；本版只抓日线。
- 不自动补全全市场。用户选几个标的就抓几个，避免无谓请求与磁盘占用。
- 不在后台定时抓取；同步是显式动作，结果与失败都会显示在界面上。

## 2. 依赖与边界

| 层 | 是否依赖 akshare | 说明 |
|---|---|---|
| `tradesome/`（应用本体） | 否 | 只读 SQLite 与 CSV，零第三方依赖 |
| `tools/akshare_sync.py` | 是（可选安装） | 唯一 `import akshare` 的地方，独立进程运行 |
| 界面 | 否 | 通过 `MarketService` 起子进程，解析 JSON 结果 |

安装：

```bat
pip install akshare
python tools\akshare_sync.py --check
```

`--check` 成功打印版本并返回 0；缺包时打印中文安装提示并返回 2。界面把这条提示原样展示，避免用户猜。

akshare 官方教程：<https://akshare.akfamily.xyz/tutorial.html>。本机在开发时无法访问该域名、也无法安装 akshare，因此实现按公开接口约定编写，并用假数据单测覆盖清洗与服务层；真实抓取需要在可联网、已安装 akshare 的机器上验证。

## 3. 数据流

```
用户选择标的/区间
      │
      ▼
DataPage ── AkshareSyncModal ── MarketService.sync_akshare()
                                      │ 子进程：python tools/akshare_sync.py ...
                                      ▼
                              akshare（stock_zh_a_hist /
                              fund_etf_hist_em / index_zh_a_hist）
                                      │ list[dict]
                                      ▼
                        akshare_csv.records_to_bars()  ← 去重、排序、坏行跳过
                                      │ List[Bar]
                                      ▼
                        akshare_csv.write_bars()  → var/data/akshare/<代码>.csv
                                      │ 标准 CSV
                                      ▼
                        MarketService.import_csv() → bars 表 → SQLite
                                      │
                                      ▼
                        回测 / 模拟盘 / 数据中心质量检查
```

- CSV 落在 `var/data/akshare/`，是审计与重放的中间产物；删掉不影响库内数据。
- 单标的失败重试一次，仍失败只记录错误，不拖垮整批。
- 界面逐标的显示“失败 N 个”的前三条原因。

## 4. 接口约定

### 4.1 `tools/akshare_sync.py`

```text
--symbols  逗号分隔，如 600519.SH,000858.SZ（必填，除非 --check）
--start    YYYY-MM-DD，默认三年前
--end      YYYY-MM-DD，默认今天
--adjust   qfq / hfq / 空（指数忽略），默认 qfq
--out      输出目录，默认 data\akshare
--sleep    每个标的间隔秒数，默认 0.4
--check    只检查 akshare 是否可用
```

正常结束时最后一行输出 JSON：

```json
{"ok": true, "bars": 2331, "start": "2023-11-10", "end": "2026-11-09",
 "files": [{"symbol": "600519.SH", "path": "...\\600519.SH.csv", "bars": 777}],
 "errors": []}
```

### 4.2 `MarketService`

| 方法 | 返回 | 说明 |
|---|---|---|
| `akshare_status()` | `{available, message}` | 调工具 `--check`，不联网 |
| `akshare_installed()` | `bool` | 用 `importlib.util.find_spec` 检查当前解释器 |
| `install_akshare(timeout=900)` | `{ok, returncode, message, output, wheels, skipped_wheels}` | 执行固定命令 `python -m pip install akshare==1.18.88`；有 vendor wheel 时只加为 `--find-links`，并跳过与当前 Python 不兼容的 wheel |
| `ensure_akshare(timeout=900)` | 同上 + `installed` | 已装直接返回；否则安装后复查，防「装到别的 Python」 |
| `sync_akshare(symbols, start=None, end=None, adjust="qfq", timeout=1800)` | `{symbols, bars, imported, errors, files}` | 抓取→写 CSV→逐份 `import_csv`，并审计 |

### 4.3 `tradesome/data/providers/akshare_csv.py`

不 import akshare/pandas，纯函数，便于单测：

- `records_to_bars(records, symbol, timeframe="1d") -> (List[Bar], skipped)`
- `write_bars(bars, path) -> int`
- `write_records(records, symbol, path) -> (count, skipped)`

字段兼容：中文（日期/开盘/最高/最低/收盘/成交量/成交额）与英文（date/open/high/low/close/volume/amount）；日期兼容 `YYYY-MM-DD`、`YYYYMMDD`、`YYYY-MM-DD HH:MM:SS`；同一日期后出现的记录覆盖前一条；OHLC 不自洽或无法解析的行计入 `skipped`。

### 4.4 自动安装 akshare

用户不需要打开命令行。三个入口共用 `ensure_akshare()`：

1. **启动时**：`Shell._ensure_data_deps()` 在界面可见后触发；缺包且 `data.auto_install_akshare=True` 时后台线程安装，成功/失败各弹一次 toast。
   - 测试/内存库（`container.memory_db=True`）跳过，避免测试联网。
   - 6 小时节流：`kv["akshare.auto_install_at"]` 记录上次尝试，失败不会每次启动都卡一次。
2. **同步弹窗**：`akshare_status()` 不可用时自动调用 `_install()`；失败显示原因和「重试安装」按钮，成功后启用「开始同步」。
3. **打包/离线**：`vendor/akshare/*.whl` 存在时安装命令追加 `--no-index --find-links vendor/akshare`，完全离线可装；说明见 `vendor/akshare/README.md`。

安装命令是固定包名，不接受界面输入：

```bat
python -m pip install --disable-pip-version-check --no-input akshare>=1.14
```

Windows 下以 `CREATE_NO_WINDOW` 运行，不会弹黑框；结果写 `data/akshare_install` 审计（成功/失败、离线包数量），失败原因同时进日志。超时 900 秒，返回可读中文；命令成功但 `akshare_installed()` 仍为 False 时，会明确提示「可能装到了其它 Python」。

## 6. 清空测试数据

### 6.1 一键清空

```bat
python -m tradesome clear-data            :: 只显示将删除多少，退出码 2
python -m tradesome clear-data --yes      :: 真正删除
```

`MarketService.purge_all()` 删除：

| 表 | 内容 |
|---|---|
| `bars` | 所有行情（含旧演示数据与导入的 CSV） |
| `backtest_runs` / `backtest_trades` | 回测历史 |
| `orders` / `fills` / `equity_snapshots` / `sessions` | 模拟盘与实盘会话记录 |

保留：配置、策略档案、审计日志（审计里会新增一条 `data/purge`）。这样“清空数据”不会误删用户辛苦搭的策略。

### 6.2 默认行为

- `config.data.auto_generate_demo` 默认 `False`；启动不再自动生成。
- `--demo` 仍可临时生成合成行情，仅用于开发/自检，正常启动不会写入。
- `demo-data` 子命令保留给测试与离线演示；README 标注为开发者命令。

## 8. 限制与排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 弹窗提示 akshare 不可用 | 自动安装失败（断网/代理/权限） | 点「重试安装」；离线放 wheel 到 `vendor/akshare/`；日志见 `var/logs/tradesome.log` |
| `--check` 返回 2 | 缺包 | 按提示安装；仍失败看是否虚拟环境 |
| 同步全部失败 | 网络/代理、接口限流 | 换时段、减少标的、加大 `--sleep` |
| 某只票区间无数据 | 停牌/退市/代码错 | 换标的或扩大区间；CSV 仍可导入 |
| 复权口径与券商不同 | 前复权基准日不同 | 用 `--adjust hfq` 或导入券商导出 CSV |
| 数据质量报警 | 缺口、除权跳变 | 数据中心「检查选中」看明细；必要时重新同步 |
